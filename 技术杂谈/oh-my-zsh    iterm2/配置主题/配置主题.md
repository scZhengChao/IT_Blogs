ls ~/.oh-my-zsh/themes

找到自己喜欢的主题，接下来就可以进行主题修改了，咱们以agnoster为例

```bash 
vim ~/.zshrc

```


这个命令也可以直接编辑

![](https://p9-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/6e979f71d0f14261a3b322a9d28be4fd~tplv-k3u1fbpfcp-jj-mark:3024:0:0:0:q75.awebp#?w=922\&h=498\&s=476207\&e=png\&b=24373b)

改完之后输入以下命令更新配置，让其生效。

```bash 
source ~/.zshrc

```


### b 第三方主题

所有第三方主题

[主题效果预览](https://link.juejin.cn/?target=https://github.com/ohmyzsh/ohmyzsh/wiki/External-themes "主题效果预览")

powerlevel10k 是目前比较流行的

![](https://p1-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/acd7b53107b24229b853666fd25d41be~tplv-k3u1fbpfcp-jj-mark:3024:0:0:0:q75.awebp#?w=1900\&h=1428\&s=564587\&e=png\&b=0e1218)

首先去`~/.oh-my-zsh/themes`目录下载主题

```bash 
cd ~/.oh-my-zsh/themes 
git clone https://github.com/romkatv/powerlevel10k.git

```


接着修改配置文件就行

```bash 
# ZSH_THEME="robbyrussell"
# ZSH_THEME="agnoster"
ZSH_THEME="powerlevel10k/powerlevel10k"

# Prompts
POWERLEVEL9K_LEFT_SEGMENT_SEPARATOR='\uE0C0'
#POWERLEVEL9K_LEFT_SUBSEGMENT_SEPARATOR='\uE0C0'
POWERLEVEL9K_RIGHT_SEGMENT_SEPARATOR='\uE0C2'
#POWERLEVEL9K_RIGHT_SUBSEGMENT_SEPARATOR='\uE0C2'
POWERLEVEL9K_LEFT_PROMPT_ELEMENTS=(dir dir_writable vcs virtualenv)
POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS=(status background_jobs command_execution_time ip)
POWERLEVEL9K_SHORTEN_DIR_LENGTH=2
POWERLEVEL9K_SHORTEN_DELIMITER=..
POWERLEVEL9K_PROMPT_ON_NEWLINE=true
POWERLEVEL9K_MULTILINE_FIRST_PROMPT_PREFIX=$'\n'
POWERLEVEL9K_MULTILINE_LAST_PROMPT_PREFIX="\uF460%F{073}\uF460%F{109}\uF460%f "
POWERLEVEL9K_MODE='nerdfont-complete'
HIST_STAMPS="yyyy/mm/dd"

```
