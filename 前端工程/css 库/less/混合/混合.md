# 命名空间、默认值

```sass (sass)  
#textMixins {
  .textLabel(@color:var(--color-black5)) {
    font-size: 14px;
    font-family: var(--font-family);
    font-weight: 400;
    color: @color;
    line-height: 20px;
  }
  .textTitle(@color: var(--color-black2),@size: 16px){
    font-size: @size;
    font-family: var(--font-family);
    font-weight: 600;
    color: @color;
  }
}
#btnMixins {
  .link-btn {
    border: none;
    padding: 0;
    height: 22px;
    line-height: 22px;
  }

}
#textMixins.textLabel('red')

```


# 传参使用

```sass (sass)  
.mixin(@color: black; @margin: 10px; @padding: 20px) {
  color: @color;
  margin: @margin;
  padding: @padding;
}
.class1 {
  .mixin(@margin: 20px; @color: #33acfe);
}
.class2 {
  .mixin(#efca44; @padding: 40px);
}
```


# when关键字

```sass (scss)  


.mixin(@a) when (lightness(@a) >= 50%) {
  background-color: black;
}
.mixin(@a) when (lightness(@a) < 50%) {
  background-color: white;
}
 .mixin(@a) {
  color: @a;
} 


```
