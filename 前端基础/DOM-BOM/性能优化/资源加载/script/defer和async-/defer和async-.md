```javascript 
 <script src="script.js"></script>
<script async src="script.js"></script>
<script defer src="myscript.js"></script>
```


在 HTML 中，`<script>`标签的`async`和`defer`属性都用于控制脚本的加载和执行行为，避免阻塞 HTML 解析，但二者在**执行时机**和**顺序保证**上有显著差异。以下是详细对比：

### **1. 普通**\*\*`<script>`（无属性）\*\*​

- **行为**：
  - **立即加载并执行脚本，同时阻塞 HTML 解析。**
  - 脚本执行完成后，继续解析后续 HTML。
- **适用场景**： &#x20;

  脚本需立即执行且依赖 DOM 的场合（需将脚本放在`<body>`末尾以减少影响）。

### **2.****`async`****（异步加载）**

- **行为**：
  - **异步加载**脚本（不阻塞 HTML 解析），加载完成后**立即执行**（可能中断 HTML 解析）。
  - **多个**\*\*`async`\*\***脚本的执行顺序不确定**（**先加载完的先执行**）。
- **适用场景**： &#x20;

  **完全独立的脚本（如统计分析、广告加载），不依赖其他脚本或 DOM。**

```html 
<script async src="analytics.js"></script> <!-- 不阻塞，执行顺序不确定 -->
```


### **3.****`defer`****（延迟执行）**

- **行为**：
  - **异步加载**脚本（不阻塞 HTML 解析），但延迟到**HTML 解析完成后、`DOMContentLoaded`事件前**按顺序执行。
  - **多个**\*\*`defer`\*\***脚本严格按文档顺序执行**。
- **适用场景**： &#x20;

  需要操作 DOM 或依赖其他脚本的场合（替代传统`DOMContentLoaded`监听）。

### **关键差异对比**

| 特性               | 普通\`\<script>\` | \`async\`      | \`defer\`             |
| ---------------- | --------------- | -------------- | --------------------- |
| **加载是否阻塞 HTML**​ | 是               | 否              | 否                     |
| **执行是否阻塞 HTML**​ | 是               | 是（加载完立即执行）     | 否（延迟到 HTML 解析完成）      |
| **执行顺序**​        | 按文档顺序           | 不确定（谁先加载完谁先执行） | 严格按文档顺序               |
| **执行时机**​        | 立即              | 加载完成后立即        | \`DOMContentLoaded\`前 |

### **可视化时间线**

```markdown 
HTML 解析: ==============================>
普通 script:      ██（加载+执行阻塞）
async script:     ░░（加载）██（执行可能阻塞）
defer script:     ░░（加载）      ██（最后执行）
```


### **如何选择？**

1. **用**\*\*`async`\*\*：
   - 脚本完全独立（如第三方统计、广告）。
   - 不关心执行顺序，且无需操作 DOM。
2. **用**\*\*`defer`\*\*：
   - 脚本依赖 DOM 或其他脚本（如主业务代码）。
   - 需要保证执行顺序（如库文件 + 业务逻辑）。
3. **无属性（普通）**：
   - 脚本需同步执行且优先级极高（极少使用，通常应避免）。

### **注意事项**

- \*\*`defer`****和****`async`\*\***仅对外部脚本有效**（带`src`的`<script>`）。
- **`type="module"`****的脚本默认行为类似****`defer`**（但可配合`async`覆盖）。
- 现代浏览器已支持`async`和`defer`的并行加载优化，无需手动合并脚本。

### **兼容性**

- 所有现代浏览器均支持`async`和`defer`（包括 IE10+）。
- 传统浏览器会忽略这些属性，退化为普通脚本行为。
