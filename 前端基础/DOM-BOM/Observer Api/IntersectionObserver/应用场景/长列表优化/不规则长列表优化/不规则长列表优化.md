# **不规则长列表优化**

这个地方 主要是 列表的宽度不固定；需要渲染出来然后计算出offset之类的高度；然后在进行一个模拟滚动；

- 上面的方法主要是用`padding`去填补 消失的列表
- 还有传统的方法不好判断滚动的方向；其实滚轮事件比较容易判断但是你不能忽略滚动条的滑动；可以参看源码的注释；如何精准判断

***

 本人写过几次 不规则 长列表：

**对开始位置和结束位置打点；用**\*\*`nextTick `****等待渲染出来以后计算出打点的****`offsetTop`****值；然后****`scrollTop`直接滚动到 ​`offsetTop`\*\***处；来实现一个模拟滚动；**

和上面的 方法相比如下差异：

- scroll 如果不去防抖的话，得加一些条件判断；return 出去一些没用的计算
- 操作了dom；计算了高度等位置信息；较慢
- 消失的列表并没有用什么来填补；而是用`scrollTop `来让列表处于一个最上或者最下位置，这个方法存在一定的缺点；理论上会闪一下；但实际看不明显
- 理论上：只要列表长度维持一致；不论是原生还是vue等框架；只应该替换元素内容；而不应该替换元素
