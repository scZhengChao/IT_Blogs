# 日期范围选择器

**适合场景**：

- 需要**复杂表单控件的应用**
- 需要自定义表单验证逻辑
- 需要**复用复杂表单组件**

![](image_3BR7NUn8bJ.png)

**场景**：**创建复杂的、可复用的表单控件，如日期选择器、富文本编辑器等。**

```html 
<!DOCTYPE html>
<html>
<head>
    <title>Date Range Picker</title>
    <style>
        body { font-family: Arial; margin: 20px; }
        form { max-width: 600px; margin: 0 auto; }
    </style>
</head>
<body>
    <form>
        <h1>Booking Form</h1>
        
        <div class="form-group">
            <label for="name">Name:</label>
            <input type="text" id="name" name="name">
        </div>
        
        <div class="form-group">
            <label>Date Range:</label>
            <date-range-picker name="date-range"></date-range-picker>
        </div>
        
        <button type="submit">Submit</button>
    </form>

    <script>
        class DateRangePicker extends HTMLElement {
            static get observedAttributes() { return ['value']; }
            
            constructor() {
                super();
                this.attachShadow({ mode: 'open' });
                this.render();
                this.startDate = null;
                this.endDate = null;
            }
            
            render() {
                this.shadowRoot.innerHTML = `
                    <style>
                        .date-range {
                            display: flex;
                            align-items: center;
                            gap: 10px;
                        }
                        input {
                            padding: 8px;
                            border: 1px solid #ddd;
                            border-radius: 4px;
                        }
                        .separator {
                            color: #666;
                        }
                    </style>
                    <div class="date-range">
                        <input type="date" id="start">
                        <span class="separator">to</span>
                        <input type="date" id="end">
                    </div>
                `;
                
                const startInput = this.shadowRoot.getElementById('start');
                const endInput = this.shadowRoot.getElementById('end');
                
                startInput.addEventListener('change', (e) => {
                    this.startDate = e.target.value;
                    this.updateValue();
                });
                
                endInput.addEventListener('change', (e) => {
                    this.endDate = e.target.value;
                    this.updateValue();
                });
            }
            
            updateValue() {
                if (this.startDate && this.endDate) {
                    this.setAttribute('value', `${this.startDate}|${this.endDate}`);
                    this.dispatchEvent(new CustomEvent('change', {
                        detail: {
                            start: this.startDate,
                            end: this.endDate
                        }
                    }));
                }
            }
            
            attributeChangedCallback(name, oldValue, newValue) {
                if (name === 'value' && newValue) {
                    const [start, end] = newValue.split('|');
                    const startInput = this.shadowRoot.getElementById('start');
                    const endInput = this.shadowRoot.getElementById('end');
                    
                    if (start) startInput.value = start;
                    if (end) endInput.value = end;
                    
                    this.startDate = start;
                    this.endDate = end;
                }
            }
        }
        
        customElements.define('date-range-picker', DateRangePicker);
        
        // 表单提交处理
        document.querySelector('form').addEventListener('submit', (e) => {
            e.preventDefault();
            const formData = new FormData(e.target);
            const dateRange = document.querySelector('date-range-picker').getAttribute('value');
            alert(`Form submitted!\nName: ${formData.get('name')}\nDate Range: ${dateRange}`);
        });
    </script>
</body>
</html>
```
