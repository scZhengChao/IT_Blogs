### **1. 添加/删除元素**

| 方法名           | 作用                      | 返回值            |
| ------------- | ----------------------- | -------------- |
| \`push()\`    | 在数组\*\*末尾\*\*添加一个或多个元素  | 新数组的\`length\` |
| \`pop()\`     | 删除数组\*\*最后一个\*\*元素      | 被删除的元素         |
| \`unshift()\` | 在数组\*\*开头\*\*添加一个或多个元素  | 新数组的\`length\` |
| \`shift()\`   | 删除数组\*\*第一个\*\*元素       | 被删除的元素         |
| \`splice()\`  | 在指定位置\*\*删除/替换/添加\*\*元素 | 被删除的元素组成的数组    |

### **2. 排序与反转**

| 方法名           | 作用                  | 返回值     |
| ------------- | ------------------- | ------- |
| \`sort()\`    | 对数组元素排序（默认按Unicode） | 排序后的原数组 |
| \`reverse()\` | 反转数组元素的顺序           | 反转后的原数组 |

### **3. 填充与填充覆盖**

| 方法名        | 作用            | 返回值     |
| ---------- | ------------- | ------- |
| \`fill()\` | 用固定值填充数组的指定区间 | 修改后的原数组 |

```javascript 
const arr = [1, 2, 3];
arr.fill(0, 1, 3); // 从索引1到3填充0
console.log(arr); // [1, 0, 0]（原数组被修改）
```


### **4. 其他修改方法**

| 方法名              | 作用                        | 返回值     |
| ---------------- | ------------------------- | ------- |
| \`copyWithin()\` | 复制数组的一部分到同一数组的另一个位置（覆盖原值） | 修改后的原数组 |

```javascript 

const arr = [1, 2, 3, 4, 5];
arr.copyWithin(0, 3); // 将索引3开始的元素复制到索引0
console.log(arr); // [4, 5, 3, 4, 5]（原数组被修改）

```
