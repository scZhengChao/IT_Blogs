白色，50%透明的两种写法

```css 
// 白色，50%透明
color: #ffffff80; 

```


```css 
// 白色，50%透明
color: rgba(255, 255, 255, .5); 
```


RGBA透明写法

`rgba(255, 255, 255, 0) `0 表示 纯透明
`rgba(255, 255, 255, 1)` 1 表示 纯不透明
