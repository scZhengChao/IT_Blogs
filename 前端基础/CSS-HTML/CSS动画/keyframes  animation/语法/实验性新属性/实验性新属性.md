### 实验性新属性

- `animation-range`：设置动画附件范围沿其时间轴的开始和结束。
- `animation-timeline`：指定用于控制 CSS 动画进度的时间轴。
- `animation-composition`：指定当多个动画同时影响同一属性时要使用的复合操作。
