## Api

- column-width:列宽  
- column-acount:列数  
- colum-gap:列间隙; 
- column-rule: 1px solid red 列边框
- column-span:列标题(只能选1/all )

渣打银行的报告同时指出，新个税不会显著降低财政收入，个人所得税降低 3630 亿元仅占 2017 年税收总额的 2.5%，新税法改革符合国务院年初提出的今年整体减税降费 1.1 万亿规模。

据悉，9月7日，财政部、税务总局下发通知，指出对纳税人在2018年10月1日（含）后实际取得的工资、薪金所得，减除费用统一按照5000元/月执行。对纳税人在9月30日（含）前实际取得的工资、薪金所得，减除费用按照税法修改前规定执行。
