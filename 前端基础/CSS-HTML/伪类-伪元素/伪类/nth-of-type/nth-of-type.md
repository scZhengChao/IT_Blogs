# nth-of-type

> \*\**`nth-of-type `******选择器只能用在标签后面*********`nth-child`**** 可以用在类名后面**

**`:nth-of-type()`** [CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS "CSS") [伪类](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Pseudo-classes "伪类")基于**相同类型（标签名称）** 的兄弟元素中的位置来匹配元素。

> `:nth-last-of-type`  和 `nth-of-type` 基本一致；从后往前匹配
