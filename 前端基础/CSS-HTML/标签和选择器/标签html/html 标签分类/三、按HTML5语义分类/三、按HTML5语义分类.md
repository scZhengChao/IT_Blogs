# 三、按HTML5语义分类

## 目录

- [1. 语义化标签](#1-语义化标签)
- [2. 非语义化标签](#2-非语义化标签)

### 1. 语义化标签

```html 
<header>        <!-- 页眉 -->
<nav>           <!-- 导航 -->
<main>          <!-- 主内容 -->
<article>       <!-- 独立文章 -->
<section>       <!-- 文档章节 -->
<aside>         <!-- 侧边栏 -->
<footer>        <!-- 页脚 -->
<figure>        <!-- 图表 -->
<figcaption>    <!-- 图表标题 -->
<time>          <!-- 时间日期 -->
```


### 2. 非语义化标签

```html 
<div>           <!-- 通用容器 -->
<span>          <!-- 通用行内容器 -->
```
