# 六、HTML5新增标签

HTML5引入了许多新的语义化标签：

```html 
<header>        <!-- 页眉 -->
<nav>           <!-- 导航 -->
<main>          <!-- 主内容 -->
<section>       <!-- 文档章节 -->
<article>       <!-- 独立内容 -->
<aside>         <!-- 侧边栏 -->
<footer>        <!-- 页脚 -->
<figure>        <!-- 图表 -->
<figcaption>    <!-- 图表标题 -->
<time>          <!-- 时间日期 -->
<mark>          <!-- 标记文本 -->
<progress>      <!-- 进度条 -->
<meter>         <!-- 度量衡 -->
<details>       <!-- 详情 -->
<summary>       <!-- 详情摘要 -->
<dialog>        <!-- 对话框 -->
```
