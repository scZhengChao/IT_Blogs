## 五、标签对比

### 1.`<div>`vs`<span>`

| 特性   | \`\<div>\` | \`\<span>\` |
| ---- | ---------- | ----------- |
| 显示类型 | 块级元素       | 行内元素        |
| 用途   | 布局容器       | 文本修饰        |
| 默认样式 | 块级显示       | 行内显示        |

### 2.`<strong>`vs`<b>`

| 特性    | \`\<strong>\` | \`\<b>\` |
| ----- | ------------- | -------- |
| 语义    | 表示重要性         | 仅表示粗体    |
| 默认样式  | 加粗            | 加粗       |
| SEO影响 | 有             | 无        |

### 3.`<em>`vs`<i>`

| 特性   | \`\<em>\` | \`\<i>\` |
| ---- | --------- | -------- |
| 语义   | 表示强调      | 仅表示斜体    |
| 默认样式 | 斜体        | 斜体       |
| 适用场景 | 强调内容      | 图标、术语等   |
