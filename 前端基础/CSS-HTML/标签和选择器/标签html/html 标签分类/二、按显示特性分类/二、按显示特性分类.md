# 二、按显示特性分类

## 目录

- [1. 块级元素 (Block-level)](#1-块级元素-Block-level)
- [2. 行内元素 (Inline)](#2-行内元素-Inline)
- [3. 行内块元素 (Inline-block)](#3-行内块元素-Inline-block)

### 1. 块级元素 (Block-level)

- 独占一行，宽度默认为父元素的100%
- 可以设**置宽高、内外边距**
- 示例：`<div>`,`<p>`,`<h1>-<h6>`,`<ul>`,`<ol>`,`<li>`,`<table>`,`<form>`

### 2. 行内元素 (Inline)

- 不独占一行，**宽度由内容决定**
- 不能**设置宽高，垂直方向的内外边距无效**
- 示例：`<span>`,`<a>`,`<strong>`,`<em>`,`<img>`,`<input>`

### 3. 行内块元素 (Inline-block)

- 不独占一行，**但可以设置宽高**
- 示例：`<img>`,`<input>`,`<button>`,`<select>`
