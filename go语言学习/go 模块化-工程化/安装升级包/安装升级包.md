### **方法一：升级到最新版本（最常用）**

使用 `go get` 命令并指定 `@latest` 标签。这是**最推荐**的方式，Go 会自动选择最新的稳定版本。

```markdown 
# 通用格式：go get <模块路径>@latest
go get code.byted.org/gorm/bytedgorm@latest
```


**执行后会发生**：

1. 1.Go 工具会查询该模块的最新版本。
2. 2.更新 `go.mod` 文件中的版本号（例如从 `v0.8.6` 升级到 `v0.9.0`）。
3. 3.下载新版本的代码到本地缓存。
4. 4.更新 `go.sum` 文件中的哈希校验值。

**验证是否升级成功**：

```go 
go list -m code.byted.org/gorm/bytedgorm
# 输出：code.byted.org/gorm/bytedgorm v0.9.0
```


### **方法二：升级到指定版本**

如果你知道需要升级的确切版本号（例如 `v0.9.2`），可以使用：

```go 
go get code.byted.org/gorm/bytedgorm@v0.9.2
```


### **方法三：** ​**升级所有依赖（谨慎使用）**

如果你想升级项目中**所有**的**直接依赖，** 可以运行：

```json 
go get -u
```


如果想升级​**​所有依赖​**​（包括间接依赖），请非常谨慎地使用：

```go 
go get -u ./...
```


**注意​**​：`go get -u ./...` 可能会引入不兼容的变更，建议在测试环境中先验证，再用于生产项目。

### **升级后的必要操作**

无论使用哪种方法，升级后都应执行以下步骤：

1. **整理依赖关系**：运行 `go mod tidy` 来清理 `go.mod` 和 `go.sum` 文件。它会移除不再需要的依赖，并添加缺失的依赖。

```go 
go mod tidy
```


2.**验证构建和测试**：确保代码升级后仍然能正常编译和通过测试。

```go 
go build ./... # 编译所有包
go test ./...  # 运行所有测试
```


3.**提交变更**：将更新后的 `go.mod` 和 `go.sum` 文件提交到版本控制系统。

```bash 
git add go.mod go.sum
git commit -m "chore(deps): upgrade bytedgorm to v0.9.0"
```
