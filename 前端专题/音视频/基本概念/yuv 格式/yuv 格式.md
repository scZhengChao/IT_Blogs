YUV 是一种颜色编码系统，常用于视频处理和图像压缩。与 RGB 不同，YUV 将亮度（Luma）和色度（Chroma）分开表示，这种分离使得 YUV 在视频压缩和传输中更加高效。

## 1.**YUV 的基本概念**

YUV 由三个分量组成：

- **Y（Luma）**：亮度分量，表示图像的明暗信息。
- **U（Cb）**：蓝色色度分量，表示蓝色与亮度的差异。
- **V（Cr）**：红色色度分量，表示红色与亮度的差异。

通过分离亮度和色度，YUV 格式可以在**不显著降低视觉质量的情况下减少数据量。**

***

## 2.**YUV 的常见格式**

YUV 有多种子格式，主要区别在于色度分量的采样方式。以下是常见的 YUV 格式：

### 2.1**YUV 4:4:4**

- 每个像素都有独立的 Y、U、V 分量。
- 色度信息没有降采样，质量最高，但数据量最大。
- 数据排列：`Y0 U0 V0 Y1 U1 V1 Y2 U2 V2 ...`

### 2.2**YUV 4:2:2**

- 水平方向上，色度分量降采样为亮度分量的一半。
- 数据量比 4:4:4 减少 1/3，质量仍然较高。
- 数据排列：`Y0 U0 Y1 V1 Y2 U2 Y3 V3 ...`

### 2.3**YUV 4:2:0**

- 水平和垂直方向上，色度分量都降采样为亮度分量的一半。
- 数据量比 4:4:4 减少一半，是最常用的格式。
- 数据排列：
  - 平面格式（Planar）：`Y0 Y1 Y2 Y3 ... U0 U1 ... V0 V1 ...`
  - 打包格式（Packed）：`Y0 Y1 Y2 Y3 U0 V0 ...`

***

## 3.**YUV 的应用场景**

- **视频压缩**：YUV 4:2:0 是大多数视频编码标准（如 H.264、H.265）的基础格式。
- **图像处理**：在图像处理中，YUV 格式可以方便地分离亮度和色度信息。
- **视频传输**：YUV 格式在视频流传输中广泛应用，如 HDMI、SDI 等。

***

## 4.**YUV 与 RGB 的转换**

YUV 和 RGB 之间可以相互转换。以下是转换公式：

### 4.1**RGB 转 YUV**

```javascript 
Y =  0.299 * R + 0.587 * G + 0.114 * B
U = -0.169 * R - 0.331 * G + 0.500 * B + 128
V =  0.500 * R - 0.419 * G - 0.081 * B + 128
```


### 4.2**YUV 转 RGB**

```python 
R = Y + 1.403 * (V - 128)
G = Y - 0.344 * (U - 128) - 0.714 * (V - 128)
B = Y + 1.770 * (U - 128)
```


## 5.**YUV 数据的存储方式**

YUV 数据可以以平面格式（Planar）或打包格式（Packed）存储。

### 5.1**平面格式（Planar）**

- Y、U、V 分量分别存储在不同的数组中。
- 示例：YUV 4:2:0 平面格式
  - `Y`数组：存储所有亮度分量。
  - `U`数组：存储所有蓝色色度分量。
  - `V`数组：存储所有红色色度分量。

### 5.2**打包格式（Packed）**

- Y、U、V 分量交错存储在一个数组中。
- 示例：YUV 4:2:2 打包格式
  - 数据排列：`Y0 U0 Y1 V1 Y2 U2 Y3 V3 ...`

## 6.**YUV 的处理工具**

### 6.1**FFmpeg**

FFmpeg 是一个强大的多媒体处理工具，支持 YUV 格式的转换和处理。

- 将视频转换为 YUV 格式：

```bash 
ffmpeg -i input.mp4 -pix_fmt yuv420p output.yuv
```


从 YUV 文件生成视频：

```bash 
ffmpeg -s 1920x1080 -pix_fmt yuv420p -i input.yuv output.mp4
```


### 6.2**OpenCV**

OpenCV 支持 YUV 格式的图像处理。

```python 
import cv2
import numpy as np

# 读取 YUV 文件
width, height = 1920, 1080
yuv_data = np.fromfile('input.yuv', dtype=np.uint8)
yuv_frame = yuv_data.reshape((height * 3 // 2, width))

# 转换为 RGB
rgb_frame = cv2.cvtColor(yuv_frame, cv2.COLOR_YUV2RGB_I420)

# 显示图像
cv2.imshow('RGB Image', rgb_frame)
cv2.waitKey(0)
```


## 7.**YUV 的性能优化**

- **硬件加速**：使用 GPU 加速 YUV 到 RGB 的转换。
- **并行处理**：利用多线程或 SIMD 指令集加速 YUV 处理。
- **内存优化**：避免频繁的内存分配和释放，使用内存池技术。

## 8.**YUV 的常见问题**

### 8.1**色度偏移（Chroma Shift）**

由于色度分量的降采样，YUV 格式可能会导致图像边缘出现色度偏移。可以通过插值算法减少这种问题。

### 8.2**颜色失真**

在 YUV 和 RGB 的转换过程中，可能会出现颜色失真。使用高精度的转换公式可以减少失真。
