# container.cloneNode(true)

## 目录

- [语句各部分解析](#语句各部分解析)

在`mxGraph`相关的操作里，`graph.container.cloneNode(true)`这个语句涉及到对`mxGraph`容器元素的深克隆操作。下面从多个方面详细介绍这个操作。

### 语句各部分解析

- **`graph`**：它是`mxGraph`类的一个实例，代表**着整个图形对象，包含了图形的各种属性、视图以及与之关联的容器等信息**。
- **`graph.container`**：`container`是`mxGraph`实例的一个属性，它指向**的是用于承载图形的 HTML 容器元素**。这个容器元素通常是一个`<div>`元素，在创建`mxGraph`实例时会将其作为参数传入，图形会被渲染到这个容器中。
- **`cloneNode(true)`**：**这是 JavaScript 中 DOM 元素的一个方法。** \*\*`cloneNode`****用于创建调用该方法的元素的一个副本。其中，参数****`true`\*\***表示进行深克隆，即除了复制元素本身，还会递归地复制该元素的所有子元素及其属性和事件监听器**（不过有些事件监听器可能需要特殊处理才能正确复制）；如果传入`false`则是浅克隆，仅复制元素本身，不复制子元素。
