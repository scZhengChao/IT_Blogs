# redirectMouseEvents

`mxEvent.redirectMouseEvents`是`mxGraph`库中的一个实用方法，其主要**作用是将鼠标事件从一个 HTML 元素重定向到另一个 HTML 元素**。这在一些特定的交互场景中非常有用，比如在图形编辑界面中，需要将鼠标事件从一个覆盖层元素传递到实际的图形区域元素上进行处理。下面详细介绍该方法。

### 方法功能

该方法允许你把**一个源元素上触发的鼠标事件**（如`mousedown`、`mousemove`、`mouseup`等）**重定向到目标元素上**，这样目标元素就可以接收并处理原本在源元素上触发的鼠标事件。

### 方法签名

```javascript 
mxEvent.redirectMouseEvents(source, target, consume);
```


### 数说明

- **`source`**：
  - **类型**：`HTMLElement`。
  - **描述**：必需参数，**代表源 HTML 元素**，也就是鼠标事件最初触发的元素。例如，可能是一个覆盖在图形区域上方的透明层元素。
- **`target`**：
  - **类型**：`HTMLElement`。
  - **描述**：必需参数，**代表目标 HTML 元素**，即重定向后鼠标事件要传递到的元素。通常是实际需要处理鼠标事件的图形区域元素。
- **`consume`**：
  - **类型**：`Boolean`。
  - **描述**：可选参数，默认值为`false`。如果设置为`true`，则在重定向鼠标事件后，**源元素上的事件将被标记为已消费，不会再触发源元素自身的默认事件处理逻辑**；如果设置为`false`，源元素上的事件处理逻辑仍然会执行。
