`lineWidth`

- **作用**：定义线条的宽度，单位为 CSS 像素。
- **默认值**：`1`
- **有效值范围**：任何正数（浮点数也可以，如`1.5`）。值为`0`时等同于`1`。

#### **性能考虑**

1. **宽线条的渲染成本**：
   - 非常宽的线条（如`lineWidth > 50`）会增加渲染负担，尤其是使用`round`或复杂`lineJoin`时。
2. **抗锯齿影响**：
   - 非整数宽度可能导致抗锯齿效果，在高性能场景中需谨慎使用。

### 注意事项

1. **半像素问题**：
   - 当线条位于半像素位置（如`x=50.5`）且`lineWidth=1`时，可能会出现模糊。
   - 解决方案：确保路径坐标为整数，或使用`lineWidth=2`。
2. **全局属性**：
   - `lineWidth`是全局属性，设置后会影响所有后续绘制的路径。如需不同宽度，需手动重置。
