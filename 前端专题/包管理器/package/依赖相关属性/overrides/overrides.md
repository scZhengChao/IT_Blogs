`pnpm.overrides` 是 pnpm 的一个​**​强制依赖版本锁定​**​机制，允许你在项目中​**​覆盖所有依赖（包括嵌套依赖）的版本​**​，确保整个依赖树使用统一的包版本。它的优先级高于 `package.json` 中的常规依赖声明，类似于 `yarn` 的 `resolutions` 或 `npm` 的 `overrides`。

## **📌 核心作用**

1. **解决版本冲突**：强制所有依赖（包括间接依赖）使用指定版本。
2. **统一依赖版本**：避免多个版本的包共存，减少打包体积和潜在问题。
3. **临时修复漏洞**：快速覆盖有安全问题的依赖版本。

## **配置方式**

在项目根目录的 `package.json` 中添加 `pnpm.overrides` 字段：

```json 
{
  "pnpm": {
    "overrides": {
      "包名": "目标版本",
      "包名@版本范围": "目标版本"
    }
  }
}
```


## **使用场景与示例**

### **1. 强制所有依赖使用同一版本**

```json 
{
  "pnpm": {
    "overrides": {
      "lodash": "4.17.21"  // 所有地方都用 lodash@4.17.21
    }
  }
}
```


**效果**：

- 无论直接依赖还是嵌套依赖（如 `A → lodash@^4.0.0` 和 `B → lodash@^3.0.0`），最终都会用 `4.17.21`。

### **2. 仅覆盖特定版本的依赖**

```json 
{
  "pnpm": {
    "overrides": {
      "lodash@^3.0.0": "3.10.1"  // 只有声明 ^3.0.0 的依赖会受影响
    }
  }
}
```


- **效果**：
  - `A → lodash@^4.0.0` → 不受影响（仍用最新 4.x）。
  - `B → lodash@^3.0.0` → 强制降级到 `3.10.1`。

### **3. 使用 ****`workspace:`**** 协议覆盖为本地包**

```json 
{
  "pnpm": {
    "overrides": {
      "utils": "workspace:*"  // 强制所有依赖使用工作区的 utils 包
    }
  }
}
```


- **效果**：
  - 即使其他依赖声明了 `utils@^2.0.0`，也会被替换为工作区内的 `utils` 包。

### **4. 递归覆盖嵌套依赖**

```json 
{
  "pnpm": {
    "overrides": {
      "react": "18.2.0",
      "react-dom": "18.2.0"  // 同时覆盖多个关联包
    }
  }
}
```


## **工作原理**

1. **优先级最高**：`overrides` 的规则会在依赖解析的最后阶段应用，覆盖其他所有声明。
2. **影响整个依赖树**：包括 `dependencies`、`devDependencies` 和嵌套依赖。
3. **不修改 `package.json`**：仅影响 `node_modules` 的实际安装结果。

## **🛠️ 调试技巧**

- 查看最终依赖树：

```bash 
pnpm list <package-name>
```


检查版本冲突来源：

```bash 
pnpm why <package-name>
```


## **对比其他工具**

| 工具       | 等效功能               | 特点                          |
| -------- | ------------------ | --------------------------- |
| \`pnpm\` | \`pnpm.overrides\` | 支持精确版本、范围匹配和 \`workspace:\` |
| \`yarn\` | \`resolutions\`    | 功能类似，语法略有不同                 |
| \`npm\`  | \`overrides\`      | 仅 npm 8+ 支持                 |
