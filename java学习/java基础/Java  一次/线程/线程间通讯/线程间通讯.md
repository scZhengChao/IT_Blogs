线程间的**通讯技术**就是通过等待和唤醒机制，来实现**多个线程协同操作完成某一项任务**，例如经典的生产者和消费者案例。等待唤醒机制其实就是让**线程进入等待状态或者让线程从等待状态中唤醒**，需要用到两种方法，如下：

- 某个线程进入等待状态时；必须有其他线程唤醒“等待状态”的线程&#x20;
- 他们都是在对象（object）上的方法

# 等待方法

```javascript 
wait() // 无限等待
wait(100) // 等待100毫秒

//  以上两个方法调用会导致 当前线程释放掉锁资源 。
```


# 唤醒方法

```java 
notify() // 唤醒同一个 对象锁处于等待状态 的 任意 一个线程；决定不了是哪一个。
notityAll() //  唤醒所有等待中的线程；

 以上两个方法调用 不会导致当前线程释放掉锁资源。
```


# 注意：

- 等待和唤醒的方法，都要**使用锁对象调用（**需要在**同步代码块中**使用）。
- 等待和唤醒方法应该使用**相同的锁对象调用。**
- **等待的方法会释放锁，** 唤醒的方法不会释放锁

# 使用细节

- `wait`方法和`notify`方法都必须绑**定在对象锁上**

```java 
Object lock = new Object(); // 对象锁 或者this

lock.wait()
lock.notify();
```


# 例子

```java 
package com.wait;

public class Test1 {
    public static void main(String[] args) {
        Runnable runnable = new Runnable( ){
            Object lock = new Object();
            boolean flag=true;

            @Override
            public void run() {
                synchronized (lock){
                    if(flag){
                        try {
                            flag = false;
                            System.out.println("进入无限等待状态");
                            lock.wait();
                            System.out.println("程序继续执行");
                        } catch (InterruptedException e) {
                            e.printStackTrace();
                        }
                    }else {
                        System.out.println("即将被唤醒");
                        try {
                            Thread.sleep(2000);
                        } catch (InterruptedException e) {
                            throw new RuntimeException(e);
                        }
                        lock.notify();
                    }
                }

            }
        };
        new Thread(runnable).start();
        new Thread(runnable).start();
    }
}

```
