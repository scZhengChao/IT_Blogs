- [抛出异常的意义所在 : throw  ](#抛出异常的意义所在--throw)

思考：&#x20;      以前出现了异常，虚拟机帮我们创建一个异常对象，抛给调用者。如果我们需要自己**手动创建一个异常对象**该如何写？

格式 ：

```java 
修饰符    返回值类型    方法名(参数列表)  {    throw new 异常类名();}
```


注意 ：

1. 抛出异常的\*\*格式必须在方法的内部完成   \*\*
2. 如果**手动抛出一个异常，下面的代码无法执**行

抛出异常的意义所在 : throw

```text 
在方法中， 当传递的参数有误，没有继续运行下去的意义了，则采取抛出处理，表示让该方法结束运行。
 告诉调用者方法中出现了问题。
```
