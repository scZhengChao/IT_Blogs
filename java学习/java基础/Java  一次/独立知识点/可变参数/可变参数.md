# 什么是

可变参数：**可以改变的参数；任意数组；**

```c# 
public 返回值类型 方法名(参数类型... 参数名){


}
```


本质上**就是数组**;只能放在**参数的最后一位**

```java 
public static int getSum(int... arr){
      int sum = 0; 
      for (int i : arr) {
          sum += i;
      }
      return sum;
}
```
