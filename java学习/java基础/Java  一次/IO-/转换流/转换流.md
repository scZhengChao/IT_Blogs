# 作用

**用来读取特定编码表的文件；**

> \*\*FIleReader 默认是UTF-8编码表；无法读取GBK的文件； \*\*

![](image_0-bCytEMB3.png)

`InputStreamReader`

自身没有读写能力；**都要依赖于普通的字节输入输出流**； （除了基础流；其他都没有读写的能力）

# `OutputStreamWriter`

```java 
// 创建文件并制定编码表
InputStreamReader isr = new InputStreamReader(new FileReader("path"),"GBK");
OutputStreamWriter  osw = new OutputStreamWriter(new FileWriter("path"),"GBK") 
```


```java 
package com.changeStream;

import java.io.FileInputStream;
import java.io.FileReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class SteamFile { 
    public static void main(String[] args) throws IOException {
        InputStreamReader ist = new InputStreamReader(new FileInputStream("files/txt.txt"), "GBK");
        int data = ist.read();
        System.out.println((char)data);
        ist.close();
    }
}

```


# 转换

![](image_HcMkySQoVW.png)

**字符流 = 字节流 + 编码表**

**最终还是用了字节流**

# 实现了字节流和字符流之间的转换

```java 
package com.changeStream;

import java.io.*;

public class Example {
    public static void main(String[] args) throws IOException {
        InputStreamReader isr = new InputStreamReader(new FileInputStream("files/test.txt"),"GBK"); 
        BufferedReader br = new BufferedReader(isr);
        String line = br.readLine();
        br.close();

        BufferedWriter bw = new BufferedWriter(new FileWriter("files/test.txt"));
        bw.write(line);
        bw.close();
    }
}

```
