## 目录

- [使用](#使用)

* 泛型没有继承；没有多态的概念；没有向下转型的概念

在语法层面可以使用通配符；表示任意类型；其实还是多态

```java 
ArrayList<?> arr = new ArrayList<Student>()
```

# 使用

基本用在方法中；但是基本不会单独使用

- 和方法的区别

```java 
public static void main(String[] args) {
        ArrayList<Object> list = new ArrayList();
        method(list);
        ArrayList<Integer> list2 = new ArrayList()
        method2(list2);
    }

    // 下限
    public static void method(ArrayList<? super Number> list){

    }
    public static void method2(ArrayList<? extends Number> list){

    }

```
