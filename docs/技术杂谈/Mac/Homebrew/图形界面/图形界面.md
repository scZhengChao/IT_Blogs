## cakebrew

如果你不熟悉终端命令，可以下载cakebrew，它是homebrew的客户端，可以实现常用的搜索、安装、卸载操作 &#x20;
官网下载安装

[ Cakebrew Cakebrew - The Mac App for Homebrew https://www.cakebrew.com](https://www.cakebrew.com " Cakebrew Cakebrew - The Mac App for Homebrew https://www.cakebrew.com")

或执行以下命令

```html 
brew cask install cakebrew

```
