&#x20;Charles 的 Map 功能分 Map Remote 和 Map Local 两种，顾名思义，**Map Remote 是将指定的网络请求重定向到另一个网址请求地址**，

**Map Local 是将指定的网络请求重定向到本地文件**。

在 Charles 的菜单中，选择 “Tools”->”Map Remote” 或 “Map Local” 即可进入到相应功能的设置页面。&#x20;

![](image_f4WEp0i1a7.png)

# MAP REMOTE

![](image_XnEqo7EeVs.png)

**mapremote**:   客户端发起请求到Charles，经过Charles转发后到服务器，服务器处理完成后将响应内容返回会Charles, 此时Charles将访问服务器2的请求结果返回为客户端

- 对于 **Map Remote** 功能，我们需要分别填写网络重定向的源地址和目的地址，对于不需要限制的条件，可以留空。下图是一个示例，[我将所有www.baidu.com](http://xn--www-zr0fu0ydiu90a.baidu.com "我将所有www.baidu.com")（**测试服务器**）的请求重定向到了[www.douban.com](https://link.jianshu.com/?t=http://www.yuantiku.com "www.douban.com")（**线上服务器**）。
- **应用场景：测试微服务与 线上微服务 切换**

![](image_eYbcaMrems.png)

# MAP LOCAL

- 对于 **Map Local** 功能，我们需要填写的重定向的源地址和本地的目标文件。对于有一些复杂的网络请求结果，**我们可以先使用 Charles 提供的 “Save Response…” 功能，将请求结果保存到本地（如下图所示），然后稍加修改，成为我们的目标映射文件。**

![](image_Vztt27Xqnd.png)

- 正常流程是： 客户端发起请求到Charles，经过Charles转发后到服务器，服务器处理完成后将响应内容返回会Charles，再由Charles返回给客户端
- **maplocal**:      客户端发起请求到Charles，经过Charles转发后到服务器，服务器处理完成后将响应内容返回会Charles, 此时Charles将本地的文件返回为客户端

**【演示一 】**：

- 1.请求右键—save response，然后另存在自己电脑的某个位置（文件属性必须为.txt）

手动生成翻倍数据：

```javascript 
#将响应写入一个文件
vi text.txt
#将文件内容读取出来并送给一个变量
raw=$(cat text.txt)
#输出查看一下变量内容
echo $raw
#数据翻倍命令
raw=$(echo "$raw" | jq \'.data.pageData+=.data.pageData\' | \'.data.pageInfo.total+=.data.pageInfo.total\')
echo $raw>atext.txt

```


- 2.请求右键/tools—map local，然后添加你刚才保存的文件，点击OK保存

![](image_7PVwaKsR_r.png)

- 3.右键请求，选择repeat(注意：有些应用会自动的切换域名)
- 4.重新刷新app的页面，会看到数据已经修改过来了。
- 5.去掉代理配置：取消勾选Tools—Maplocal即可

![](image_IVWlomddsp.png)
