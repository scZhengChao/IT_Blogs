## [修改终端 Terminal 为 GitBash](https://blog.csdn.net/ling_kedu/article/details/104653765/ "修改终端 Terminal 为 GitBash")

1.打开设置（快捷键： Ctrl + Alt + S ），进入 Plugins,搜索栏搜索 Terminal，查看 Terminal插件是否打勾选中，如果没有，请打勾。
2.进入设置（快捷键：Ctrl + Alt + S），进入 Tools字段，再进入 Terminal字段，在 Shell path那一栏中，输入你主机 Git Bash的安装位置

```bash 
"C:\Program Files\Git\bin\sh.exe" -login -i
```

## 常用插件

### Rainbow Brackets&#x20;

彩虹颜色的括号 看着很舒服 敲代码效率变高

### Material Theme UI&#x20;

默认内置了多种配色，

Preferences/Settings -> Appearance -> Material Theme&#x20;

中可以进行切换。

### .ignore&#x20;

直接在文件列表中右键，可以快速根据模板生成一系列的 .ignore 文件，比如 .dockerignore、.gitignore 等等。&#x20;

### CodeGlance&#x20;

编辑器右侧显示代码缩略图

### GitToolBox&#x20;

其实就是给 ide扩展了一下 git相关的功能

### Atom Material Icons&#x20;

换换侧边栏中各种文件类型对应的图标，顺手装上不会有错的。&#x20;

### [Codota](https://link.zhihu.com/?target=https%3A//plugins.jetbrains.com/plugin/7638-codota "Codota")

快速编写 javascript  和  java

## 卸载webstorm mac

```纯文本 
使用find ~ -iname '*webstorm*'命令查找须要卸载的地方, 能够使用ls命令查看是否已删除.net
sudo find ~ -iname '*webstorm*'
```
