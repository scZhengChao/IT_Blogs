# 将控制台修改直接同步源文件代码

很多时候我们都会在`source`调试我们的元素样式，然后再将**调整好的样式复制到编辑器的源代码**中。那么这个设置将省略复制的这一步，将在source修改的样式直接修改到源文件中。

设置方式，在`FileSystem`选项卡中点击“`add folder to workspace`”,选中你的项目文件即可（mac系统会询问权限许可，需同意）
