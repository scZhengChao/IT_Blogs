#### 1. Rust 程序设计语言 中文版（《Rust 圣经》）

- **地址**：[https://kaisery.github.io/trpl-zh-cn/](https://kaisery.github.io/trpl-zh-cn/ "https://kaisery.github.io/trpl-zh-cn/")
- **特点**：官方《The Rust Programming Language》的**完整中文翻译版**，内容和官方同步，是 Rust 入门到进阶的**唯一权威教材**，覆盖基础语法、所有权、生命周期、并发、泛型、模式匹配等核心知识点，讲解细致且贴合新手，配套大量可运行的代码示例。
- **适用**：零基础入门、系统学习 Rust 核心原理，是所有 Rust 开发者的**第一本必读书**。

#### 2. Rust 标准库中文文档

- **地址**：[https://rustwiki.org/zh-CN/std/](https://rustwiki.org/zh-CN/std/ "https://rustwiki.org/zh-CN/std/")
- **特点**：Rust 官方标准库的**实时同步中文翻译**，包含所有标准库模块（如`std::collections`、`std::fs`、`std::sync`）、函数、结构体的详细说明和使用示例，开发中查 API 的**首选工具**。
- **补充**：也可使用官方英文文档的中文切换功能（[https://doc.rust-lang.org/std/](https://doc.rust-lang.org/std/ "https://doc.rust-lang.org/std/")），部分版本翻译稍滞后，rustwiki 版更新更及时。

#### 3. Rust by Example 中文版（示例驱动学习）

- **地址**：[https://rustwiki.org/zh-CN/rust-by-example/](https://rustwiki.org/zh-CN/rust-by-example/ "https://rustwiki.org/zh-CN/rust-by-example/")
- **特点**：官方《Rust by Example》的翻译版，**以代码示例为核心**，跳过冗长文字，直接通过 “示例 + 注释” 讲解语法和用法，适合**喜欢边练边学**的开发者，快速掌握基础语法和常用特性。
- **适用**：有编程基础（如 Go/Java/JS），想快速上手 Rust 基本用法，无需逐字看理论的场景。
