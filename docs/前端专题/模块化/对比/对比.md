### \*\*1) \*\*​**`CommonJS (CJS)`**

- **适用环境**：Node.js（默认使用）。
- **特点**：
  - 同步加载（不适合浏览器）。
  - 使用 `require()`和 `module.exports`。
- **示例**：

```javascript 
const fs = require('fs');
module.exports = { foo: 'bar' };
```


### \*\*2) \*\*​**`ES Module (ESM)`**

- **适用环境**：**现代浏览器**（[script标签esm模块化](<script标签esm模块化.md> "script标签esm模块化")）和打包工具（Webpack、Rollup）。
- **特点**：
  - 静态导入/导出（`import`/ `export`）。
  - 支持 Tree Shaking（优化打包体积）。
- **示例**：

```typescript 
import { foo } from './module.js';
export const bar = 'baz';
```


### **(3) ****`UMD`****(Universal Module Definition)**

- **适用环境**：兼容浏览器、Node.js 和 AMD（如 RequireJS）。
- **特点**：
  - 会检测当前环境并选择合适的模块加载方式。
  - 体积较大（包含兼容代码）。
- **示例**：

```javascript 
(function (root, factory) {
  if (typeof define === 'function' && define.amd) {
    define(['exports'], factory);
  } else if (typeof exports === 'object') {
    factory(exports);
  } else {
    factory(root.myLib = {});
  }
})(this, function (exports) {
  exports.foo = 'bar';
});
```
