# commit 规范

```typescript 
feat : 新功能、新特性
fix : BUG 修复
docs : 修改 readme 等文档
style : 修改缩进、文件编码等格式化
perf : 性能优化
test : 增加测试
chore : 修改项目编译、部署等构件配置
refactor : 重构代码

```
