# 导入导出相关属性

常见的环境，基本上分为浏览器browser和node环境两大类，接下来我们来看看package.json中，跟环境相关的配置属性。环境的定义可以简单理解如下：

- browser环境：比如存在一些只有在浏览器中才会存在的全局变量等，比如window，Document等
- node环境: npm包的源文件中存在只有在node环境中才会有的一些变量和内置包，内置函数等。
