# package-lock.json

在`npm 5.x`版本新增了`package-lock.json`文件，而安装方式还沿用了`npm 3.x`的扁平化的方式。它描述了生成的确切树，以便后续安装能够生成相同的树，而不管中间依赖更新如何。
