“洋葱模型”是许多现代 Node.js Web 框架（如 Express、Koa、Fastify 等）中用于描述​**​****中间件执行流程****​**​的一种设计模式。它的核心思想是：​**​请求从外到内依次经过所有中间件，然后再从内到外依次返回​**​，就像剥洋葱一样，一层一层地进入和返回。

## 🧅 什么是“洋葱模型”？

在“洋葱模型”中：

- **请求（Request）** 从**最外层的中间件开始进入，逐层向内传递**；
- 在中间过程中，**每个中间件都可以对请求进行处理**（如解析数据、鉴权、日志记录等）；
- 当请求到达最内层的目标处理逻辑（如路由处理器）后；
- **响应（Response）** 从**内向外逐层返回，在返回的过程中，中间件依然可以修改响应内容**（如添加头部、统一格式化等）。

这种机制使得我们可以在请求的不同阶段插入不同的逻辑，非常灵活。
