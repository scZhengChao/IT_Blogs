在`mxGraph`里，`edgeLabelsMovable`是`mxGraph`类的一个属性，**用于控制边的标签是否可以被用户移动**。下面从功能概述、使用方式、使用场景、示例代码以及代码解释等方面详细介绍。

### 功能概述

在`mxGraph`中，**边（如连接两个节点的线条）可以附带标签，用于说明边所代表的关系或信息**。`edgeLabelsMovable`属性决定**了这些边的标签是否能够被用户通过鼠标拖动等操作来改变其位置**。当`edgeLabelsMovable`设置为`true`时，用户可以自由移动边的标签到合适的位置；当设置为`false`时，边的标签位置将固定，用户无法对其进行移动操作。

### 使用方式

可以通过直接设置`mxGraph`实例的`edgeLabelsMovable`属性来启用或禁用边标签的移动功能，示例代码如下：

```typescript 
// 创建 mxGraph 实例
const graph = new mxGraph(container);

// 启用边标签移动功能
graph.edgeLabelsMovable = true;

// 禁用边标签移动功能
graph.edgeLabelsMovable = false;
```


### 使用场景

- **灵活布局需求**：在一些图形绘制场景中，用户可能需要根据图形的整体布局和美观性，灵活调整边标签的位置。例如，在绘制复杂的流程图时，为了避免标签相互重叠或者遮挡其他元素，用户可以自由移动边标签到合适的位置，此时可以将`edgeLabelsMovable`设置为`true`。
- **固定格式要求**：对于一些具有固定格式要求的图形，如标准的组织结构图、数据库关系图等，边标签的位置可能需要保持固定，以保证图形的规范性和一致性。这种情况下，将`edgeLabelsMovable`设置为`false`可以防止用户误操作改变标签位置。
- **不同操作模式切换**：根据用户的不同操作阶段或权限，动态地调整边标签是否可移动。例如，在编辑模式下允许用户移动边标签以进行布局调整，而在查看模式下禁止移动边标签，以保持图形的稳定性。
