```javascript 
graph.importCells([cell], x, y, target)
```


在`mxGraph`中，`graph.importCells([cell], x, y, target)`方法用于将一组单元格（`cells`）导入到图形（`graph`）中指定的位置。下面详细解释该方法的各个参数及作用：

### 方法参数

1. **`[cell]`**
   - 这是一个数组，数组中的每个元素代表一个要导入的单元格。在`mxGraph`里，单元格可以是节点（`Vertex`）、边（`Edge`）等图形元素。例如，你可以先创建一个或多个单元格，然后将它们放在数组里传递给这个方法，以实现将这些单元格导入到图形中的目的。
2. **`x`**
   - 这是一个数字类型的参数，表示导入的单元格在图形中放置位置的水平坐标（以像素为单位）。它决定了单元格在图形的水平方向上的起始位置。
3. **`y`**
   - 同样是数字类型，代表导入的单元格在图形中放置位置的垂直坐标（以像素为单位）。它决定了单元格在图形的垂直方向上的起始位置。
4. **`target`**
   - 该参数指定了导入的单元格的目标父级单元格。如果传入`null`或者不传入该参数，默认会使用图形的默认父级单元格。目标父级单元格决定了导入的单元格在图形的层次结构中的位置。

### 方法返回值

该方法会返回一个数组，数组中包含了实际导入到图形中的单元格对象。
