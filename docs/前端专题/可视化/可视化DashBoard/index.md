# DataV

[介绍 | DataV Vue 大屏数据展示组件库 http://datav.jiaminghi.com/guide/#%E7%94%A8%E5%89%8D%E5%BF%85%E7%9C%8B](http://datav.jiaminghi.com/guide/#%E7%94%A8%E5%89%8D%E5%BF%85%E7%9C%8B "介绍 | DataV Vue 大屏数据展示组件库 http://datav.jiaminghi.com/guide/#%E7%94%A8%E5%89%8D%E5%BF%85%E7%9C%8B")

## 介绍

组件库基于Vue （React版） ，主要用于构建大屏（全屏）数据展示页面即数据可视化，具有多种类型组件可供使用：

- 边框

带有不同边框的容器

- 装饰

用来点缀页面效果，增加视觉效果

- 图表

图表组件基于

[Charts](http://charts.jiaminghi.com/ "Charts")

封装，轻量，易用

- 其他

飞线图/水位图/轮播表/...

```typescript 
 npm install @jiaminghi/data-view
```

# bizcharts

[ Bizcharts - 基于商业场景下的数据可视化解决方案  https://bizcharts.taobao.com/product/BizCharts4/category/61/page/98](https://bizcharts.taobao.com/product/BizCharts4/category/61/page/98 " Bizcharts - 基于商业场景下的数据可视化解决方案  https://bizcharts.taobao.com/product/BizCharts4/category/61/page/98")

## 特性

- 是基于 G2 4.X 封装的 React 图表库，具有 G2、React 的全部优点，可以让用户以组件的形式组合出无数种图表
- 集成了大量的统计工具，支持多种坐标系绘制，交互定制，动画定制以及图形定制等
- 性能稳定且具有强大的扩展能力和高度自定义能力
- 内置了[g2Plot的42个基础图表](https://bizcharts.taobao.com/product/BizCharts4/category/77/page/116 "g2Plot的42个基础图表")

```typescript 
npm install bizcharts --save
```
