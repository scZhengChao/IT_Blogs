## 一、模糊效果绘制

### 1. 使用`filter`属性（现代浏览器支持）

![](image_mHRi_r8rtP.png)

```html 
<canvas id="blurCanvas" width="400" height="200"></canvas>
<script>
const blurCanvas = document.getElementById('blurCanvas');
const blurCtx = blurCanvas.getContext('2d');

// 绘制一个矩形并应用模糊
blurCtx.fillStyle = 'blue';
blurCtx.filter = 'blur(5px)'; // 5px模糊效果
blurCtx.fillRect(50, 50, 100, 100);

// 重置filter以绘制清晰图形
blurCtx.filter = 'none';
blurCtx.fillStyle = 'red';
blurCtx.fillRect(200, 50, 100, 100);
</script>
```


### 2. 使用`globalAlpha`实现半透明模糊效果

![](image_LQxjvGKYCI.png)

```html 
<canvas id="alphaCanvas" width="400" height="200"></canvas>
<script>
const alphaCanvas = document.getElementById('alphaCanvas');
const alphaCtx = alphaCanvas.getContext('2d');

// 绘制底层图形
alphaCtx.fillStyle = 'blue';
alphaCtx.fillRect(50, 50, 100, 100);

// 设置半透明
alphaCtx.globalAlpha = 0.5;
alphaCtx.fillStyle = 'white';
alphaCtx.fillRect(70, 70, 100, 100);
alphaCtx.globalAlpha = 1.0; // 重置透明度
</script>
```


## 二、阴影线条绘制

### 1. 使用`shadow`相关属性

```javascript 
o2d.shadowOffsetX=number x 方向偏移
o2d.shadowOffsetY=number y 方向偏移
o2d.shadowBlur=number 模糊、失焦、扩散
o2d.shadowColor='blue/#xxxxx/rgb/rgba'

```


![](image_ziEh90OSnE.png)

```html 
<canvas id="shadowCanvas" width="400" height="200"></canvas>
<script>
const shadowCanvas = document.getElementById('shadowCanvas');
const shadowCtx = shadowCanvas.getContext('2d');

// 设置阴影属性
shadowCtx.shadowColor = 'rgba(0, 0, 0, 0.5)'; // 阴影颜色
shadowCtx.shadowBlur = 10; // 模糊程度
shadowCtx.shadowOffsetX = 5; // X轴偏移
shadowCtx.shadowOffsetY = 5; // Y轴偏移

// 绘制带阴影的矩形
shadowCtx.fillStyle = 'green';
shadowCtx.fillRect(50, 50, 100, 100);

// 绘制带阴影的线条
shadowCtx.beginPath();
shadowCtx.moveTo(200, 50);
shadowCtx.lineTo(300, 150);
shadowCtx.strokeStyle = 'red';
shadowCtx.lineWidth = 5;
shadowCtx.stroke();

// 重置阴影设置
shadowCtx.shadowColor = 'transparent';
</script>
```


### 2. 使用多层绘制模拟高级阴影

![](image_ZR3UG_J5PA.png)

```html 
<canvas id="multiShadowCanvas" width="400" height="200"></canvas>
<script>
const multiCanvas = document.getElementById('multiShadowCanvas');
const multiCtx = multiCanvas.getContext('2d');

// 绘制底层阴影（模糊效果）
multiCtx.fillStyle = 'rgba(0, 0, 0, 0.2)';
multiCtx.filter = 'blur(8px)';
multiCtx.fillRect(62, 62, 100, 100);

// 重置filter绘制主体
multiCtx.filter = 'none';
multiCtx.fillStyle = 'purple';
multiCtx.fillRect(50, 50, 100, 100);
</script>
```


## 三、性能影响对比

| 方法              | 性能影响 | 适用场景       | 备注        |
| --------------- | ---- | ---------- | --------- |
| \`filter\`属性    | 较高   | 现代浏览器，简单模糊 | 会影响后续绘制   |
| \`globalAlpha\` | 低    | 半透明效果      | 不能实现真正的模糊 |
| \`shadow\`属性    | 中到高  | 阴影效果       | 阴影复杂时性能下降 |
| 多层绘制            | 高    | 自定义高级效果    | 最灵活但最耗性能  |

## 四、最佳实践建议

1. **简单模糊**：使用`filter`属性最简单

```javascript 
ctx.filter = 'blur(5px)';
// 绘制内容
ctx.filter = 'none'; // 使用后记得重置
```


​**​  2.阴影效果​**​：使用`shadow`属性

```javascript 
ctx.shadowColor = 'rgba(0, 0, 0, 0.5)';
ctx.shadowBlur = 10;
ctx.shadowOffsetX = 5;
ctx.shadowOffsetY = 5;
// 绘制内容
ctx.shadowColor = 'transparent'; // 重置
```


1. **性能优化**：
   - 尽量减少模糊/阴影区域的大小
   - 避免在动画中频繁使用这些效果
   - 对于复杂效果，考虑使用离屏Canvas预渲染
