# setCellsResizable

在`mxGraph`中，`setCellsResizable`是`mxGraph`类的一个方法，用于设置图形中**单元格（如节点、边等）是否可调整大小**。下面从功能概述、参数、使用场景、示例代码及代码解释等方面详细介绍该方法。

### 功能概述

`setCellsResizable`方法允许开发者控制`mxGraph`中指定单元格或者所有单元格是否能够被用户调整大小。当设置为可调整大小时，用户可以通过鼠标拖动单元格的边框来改变其尺寸；当设置为不可调整大小时，单元格的大小将保持固定，用户无法通过常规操作改变其尺寸。

### 参数

该方法接收两个参数：

- **`cells`**：类型可以是`Array<mxCell>`或者`mxCell`，也可以为`null`。如果传入一个`mxCell`数组，那么这些指定的单元格将应用设置；如果传入单个`mxCell`对象，则只有该单元格应用设置；如果传入`null`，则表示对图中所有单元格应用设置。
- **`resizable`**：类型为`boolean`，表示是否允许单元格调整大小。`true`表示允许调整大小，`false`表示不允许。

### 使用场景

- **固定布局需求**：在某些情况下，图形的布局需要保持固定，不希望用户随意调整单元格大小。例如，在展示一些标准流程图或者组织结构图时，为了保证图形的规范性和一致性，可以将所有单元格设置为不可调整大小。
- **部分元素特殊处理**：对于图形中的某些特殊元素，可能不希望其大小被改变。比如，一些标识性的节点或者固定大小的图例等，可以将这些特定的单元格单独设置为不可调整大小。
- **交互控制**：根据用户的操作权限或者不同的交互阶段，动态地控制单元格是否可调整大小。例如，在编辑模式下允许调整大小，在查看模式下禁止调整大小。
