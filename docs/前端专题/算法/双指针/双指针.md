双指针算法是一种通过使用两个指针（或迭代器）在数据结构（如数组、链表等）中协同遍历来高效解决问题的技巧。它通常能将暴力解法的时间复杂度从 O(n²) 优化到 O(n) 或 O(nlogn)，特别适合解决**线性序列上的查找、匹配或计算问题**。以下是双指针算法的典型应用场景和适用条件：

### **一、适合用双指针解决的问题类型**

1. **有序数组/链表的查找问题**
   - **两数之和**（LeetCode 167）：在有序数组中找两个数，使它们的和等于目标值。
   - **三数之和**（LeetCode 15）：先固定一个数，转化为两数之和问题。
   - **合并两个有序数组/链表**（LeetCode 88/21）。
2. **滑动窗口问题（子数组/子串）**
   - **最长无重复子串**（LeetCode 3）：维护一个无重复字符的窗口。
   - **最小覆盖子串**（LeetCode 76）：找到包含目标字符的最短子串。
   - **固定长度的子数组和**（如大小为 k 的子数组的最大平均值）。
3. **快慢指针问题**
   - **链表中环的检测**（LeetCode 141）：快指针每次走两步，慢指针走一步。
   - **链表的中间节点**（LeetCode 876）：快指针到末尾时，慢指针指向中点。
   - **删除链表的倒数第 N 个节点**（LeetCode 19）：快指针先走 N 步，再同步移动。
4. **前后指针（反向双指针）**
   - **反转数组/字符串**（LeetCode 344）：左右指针向中间交换元素。
   - **验证回文串**（LeetCode 125）：忽略非字母数字字符后，左右指针比对。
   - **盛最多水的容器**（LeetCode 11）：移动高度较小的指针以寻找更大面积。
5. **分离双指针（两个序列）**
   - **判断子序列**（LeetCode 392）：一个指针遍历主序列，另一个跟踪子序列。
   - **区间列表的交集**（LeetCode 986）：两个指针分别遍历两个区间列表。

### **二、何时优先考虑双指针？**

1. **数据已排序或可排序：** 如两数之和、三数之和等问题，排序后能简化指针移动逻辑。
2. **线性结构上的高效遍历需求****：需要将 O(n²) 暴力解法优化到 O(n) 或 O(nlogn) 时。** ​
3. **明显的窗口或区间性质**：如**子串、子数组问题中需要动态调整窗口**大小。
4. **链表操作**：**涉及环、中点、倒数节点等问题时，快慢指针是经典解法。**
5. **对称或反向操作**：**如反转、回文等问题，前后指针可以同步向中间逼近**。

***

### **三、双指针算法的核心思想**

- **指针移动的单调性**：通过条件判断（如大小比较、覆盖要求）决定移动哪个指针，**确保每次操作都能缩小问题范围。**
- **避免重复计算**：通过指针的移动跳过无效状态（如滑动窗口中的冗余字符）。
- **空间复杂度优化**：通常只需常数空间（O(1)），优于哈希表等额外数据结构。
