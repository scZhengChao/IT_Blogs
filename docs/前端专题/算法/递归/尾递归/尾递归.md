# 尾递归

**尾递归**是指一个**函数在调用自身之后不再执行任何其他操作**，而是将**返回值直接传递给函数调用的上级**，**从而避免了新的调用栈帧的创建**。换句话说，**尾递归是指递归调用发生在函数的最后一个语句中，从而使得函数调用不需要保存多个调用栈帧，而只需一个即可。**

具体来说，**尾递归的实现方式通常是在递归函数内部引入额外的参数来保存中间结果，这样每次递归调用时，只需要更新这些参数的值，而不是创建新的栈帧。这使得程序可以高效地处理大量递归调用，而不会导致栈溢出的问题。**

例如，在计算斐波那契数列时，普通递归方法会因为需要存储大量的中间结果而导致效率低下和内存占用过多。然而，通过**使用尾递归优化，** 我们可以将计算过程中的中间结果作为参数传递给下一次递归调用，从而避免了不必要的栈帧创建，减少了内存消耗。这种优化不仅适用于斐波那契数列，还可以应用于其他需要大量递归调用的场景，如深度优先搜索算法等。

在ECMAScript 6中，**支持尾递归优化意味着如果一个函数的最后一个操作是函数调用，那么这个调用会被视为尾调用**，并且可以**被优化为“跳转”而非“子调用”**。这意味着在严格模式下，**使用尾递归优化的函数可以避免栈溢出问题，即使面对非常大的输入也能正常运行。**
