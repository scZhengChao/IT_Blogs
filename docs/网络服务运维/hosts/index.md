**hosts文件是一个本地的域名解析系统文件**，用于将域名映射到IP地址，**优先级高于DNS服务器**。

## **主要作用：**

### 1. **本地域名解析**

- 手动指定域名对应的IP地址
- 格式：`IP地址 域名`
- 示例：`127.0.0.1 localhost`

### 2. **常见用途**

- **屏蔽广告/恶意网站**：将不良域名指向本地(127.0.0.1)
- **开发测试**：**将域名指向测试服务器**
- **访问受限内容**：**绕过DNS污染**
- **网络调试**：快速切换测试环境
- **加速访问**：**将CDN域名指向最优IP**

### 3. **文件位置**

- **Windows**: `C:\Windows\System32\drivers\etc\hosts`
- **Mac/Linux**: `/etc/hosts`

### 4. **工作流程**

```markdown 
访问域名 → 先检查hosts文件 → 有记录则使用 → 无记录则查询DNS
```


### 5. **修改注意事项**

- 需要管理员/root权限
- 修改后立即生效（浏览器可能需要清理缓存）
- 每行一条记录
- `#`号开头表示注释

**示例：**

```markdown 
# 屏蔽广告网站
127.0.0.1 ad.example.com

# 开发环境映射
192.168.1.100 myapp.test

# 强制使用特定IP
104.18.32.32 cdn.example.com
```


hosts文件是网络配置的基础工具，简单但功能强大。
