# 包

## 目录

- [导入](#导入)
- [导出](#导出)

在Go中，程序是通过将包链接在一起来构建的

- **最基本的调用单位是包**，而不是go文件
- **包其实就是一个文件夹**，**包内共享所有源文件的变量，常量，函数以及其他类型。**
- **建议都是小写字母，并且要尽量简短。**

### 导入

- 起别名

```go 
import e "example"

```


- 批量导入

```go 
import (
   "fmt"
   "math"
)

```


- 只导入不调用，通常这么做是为了调用该包下的`init`函数。

```go 

import (
   "fmt"
    _ "math" // 下划线表示匿名导入
)



```


> 注意
> **在Go中完全禁止循环导入，不管是直接的还是间接的**。例如包A导入了包B，包B也导入了包A，这是直接循环导入，包A导入了包C，包C导入了包B，包B又导入了包A，这就是间接的循环导入，存在循环导入的话将会无法通过编译。

### 导出

**对外暴露的函数和变量可以被包外的调用者导入和访问，如果是不对外暴露的话，那么仅包内的调用者可以访问，外部将无法导入和访问**

- 在Go中，**导出和访问控制是通过命名来进行实现的**，
- 如果想要对外暴露一个函数或者一个变量 **，只需要将其名称首字母大写即可**，
- 如果想要不对外暴露的话，只需将**名称首字母改为小写即可**
- **该规则适用于整个Go语言**，结构体及其字段，方法，自定义类型，接口等等
