# **指针类型**

#### 在 **类型声明** 中

```go 
func (d *Dog) Run() { ... }
```


- 这里的 `*Dog`表示 **方法的接收器类型是指针类型**（即 `Dog`结构体的指针）。
- 它并不是解引用操作，而是 **类型定义的一部分**，表明 `Run()`方法绑定到 `*Dog`类型上。

#### 在 **变量操作** 中

```go 
dog := &Dog{}  // dog 是 *Dog 类型（指针）
*dog           //  这才是解引用操作，获取指针指向的值
```


`*`的具体含义取决于上下文：

- **在 ****类型定义**** 中（如 ****`*Dog`****）：表示指针类型。**
- **在 ****表达式**** 中（如 ****`*dog`****）：表示解引用操作。**
