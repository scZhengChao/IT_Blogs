# 206

状态码 206 Partial Content 是 HTTP 协议中的一个状态码 。

**基础概念**

- 它表示服务器已经成功处理了部分 GET 请求。也就是说，客户端请求的是资源的一部分，服务器按照请求成功返回了这部分资源。

**常见应用场景**

- **视频、音频等大文件断点续传**：当你下载一个大视频文件，中途网络中断后再恢复下载时，客户端会告诉服务器从之前中断的位置继续下载。服务器就会返回状态码 206，并发送从该位置开始的那部分文件内容。
- **范围请求**：比如客户端只想获取一个图片的某一部分数据，向服务器发起带有范围请求头（如`Range` 头）的请求，服务器若支持这种范围请求，就会返回 206 状态码以及相应范围的图片数据。

**与其他状态码的对比**

- 和 200 OK 状态码不同，200 表示整个请求的资源完整返回，而 206 只返回请求的部分资源。例如完整下载一个文件返回 200，而分块下载时每成功下载一块，若符合部分内容请求，就返回 206 。
