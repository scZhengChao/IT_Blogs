该工具旨在成为构建和使用 `rust` 生成的 `WebAssembly` 的**一站式商店**， 您希望与 JavaScript、浏览器或 Node.js 进行互操作。`wasm-pack`**帮助您构建 rust 生成的 WebAssembly 包**，您可以将其发布到 npm 仓库， 或者与您已经使用的**工作流中的任何 javascript 包一起使用，例如**[**webpack**](https://webpack.js.org/ "webpack")**。**

这个项目是[rust-wasm](https://github.com/rustwasm/team "rust-wasm")组的一部分。您可以通过访问该存储库找到更多信息！
