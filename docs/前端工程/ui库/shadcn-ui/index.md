# shadcn/ui

基于`react`

这**不是**一个组件库。这是一个可重复使用的组件集合，您可以将组件的源码复制并粘贴到您的应用程序中直接使用。

你说的“**不是组件库**”是什么意思？

我的意思是，你不能把它当作一个依赖包来安装。即，它不能通过 npm 安装或发布。

选择你需要的组件，然后将源码复制并粘贴到你的项目中，再根据你自己的需求进行定制。代码就是你的了。
