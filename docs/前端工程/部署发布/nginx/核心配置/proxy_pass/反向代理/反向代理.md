# 反向代理

- 接下来我们介绍反向代理，客户端对代理无感知，客户端不需要任何配置，我**们只需要将请求发送到反向代理服务器，然后由反向代理服务器去选择目标服务器获取数据后，** 再返回给客户端。此时反向代理服务器和目标服务器对外就是一个服务器。**显然，反向代理对外暴露的是反向代理服务器，隐藏了真实服务器**

比如下图中，我们想目标服务器发出请求时，由反向代理服务器选择 tomcat 服务器 8001 端口，获取数据后，再将数据返回给客户端 &#x20;
