## 加密方案简述

### 对称加密&#x20;

对称加密就是两边拥有相同的秘钥，两边都知道如何将密文加密解密。&#x20;

这种加密方式固然很好，但是问题就在于如何让双方知道秘钥。&#x20;

由于传输数据都是走的网络，如果将秘钥通过网络的方式传递的话，一旦秘钥被截获就没有加密的意义&#x20;

### 非对称加密&#x20;

有公钥私钥之分：&#x20;

- 公钥所有人都可以知道，**可以将数据用公钥加密，但是将数据解密必须使用私钥解密**
- 私钥只有分发放公钥的一方才知道

这种加密方式就可以完美解决对称加密存在的问题 通过对比，选用保密性好的 **非对称加密**方案作为加密方案 本文选用 **RSA**

**\[1]** 对称加密算法

## 公私钥生成

根据百度经验的建议,生成一个1024位的的秘钥 这里使用**openssl**生成，window下建议在Git Bash下使用&#x20;

**私钥**

```javascript 
 openssl genrsa -out rsa_1024_priv.pem 1024
```


**公钥**

```javascript 
 openssl rsa -pubout -in rsa_1024_priv.pem -out rsa_1024_pub.pem
```
