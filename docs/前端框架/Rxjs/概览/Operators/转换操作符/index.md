# 转换操作符

那么什么是转换操作符呢，众所周知，我们在日常业务中，总是需要**与各种各样的数据打交道**，很多时候我们**都不是直接就会对传输过来**的数据进行使用，而是**会对其做一定的转换**，让他成为**更加契合我们需求的形状**，这就是转换操作符的作用所在了。
