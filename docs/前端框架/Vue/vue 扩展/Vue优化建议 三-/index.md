# 1.数据可响应

        经常遇到这样的情况；后端返回

**的list数据是固定的，但是你想给某一个数据做标记；这个时候后端并没有返回你要的那个字段；怎么办咧！**

```vue 
 this.$set(target,property/index,value)
//无论你嵌套层级有多深；只要改数据原本是响应式的；视图就会响应
```


但是要注意：不要忘了你加了数据

# 3.路由完成后的成功打断回调

            在 2.2.0+，可选的在 router.push 或 router.replace 中

**提供 onComplete 和 onAbort 回调作为第二个和第三个参数**

。这些回调将会在导航成功完成 (在所有的异步钩子被解析之后) 或终止 (导航到相同的路由、或在当前导航完成之前导航到另一个不同的路由) 的时候进行相应的调用。

        在 3.1.0+，可以省略第二个和第三个参数，此时如果支持 Promise，router.push 或 router.replace 将返回一个 Promise。
