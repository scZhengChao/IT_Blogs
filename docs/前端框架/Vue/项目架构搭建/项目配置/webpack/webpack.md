# lintOnSave

vue中lintOnSave配置

Type: [boolean](https://so.csdn.net/so/search?q=boolean\&spm=1001.2101.3001.7020 "boolean") | 'warning' | 'default' | 'error'

Default: true

用途:   设置是否在开发环境下每次保存代码时都启用 [eslint](https://so.csdn.net/so/search?q=eslint\&spm=1001.2101.3001.7020 "eslint")验证。
