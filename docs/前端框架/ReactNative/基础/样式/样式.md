# **背景色透明问题**

**使用postion  同一层级 会导致自 背景色 透明 问题 ：加上 zIndex 就可以了**

**父样式如果有背景色，子元素也有背景色且有透明的话，会重叠影响**

Text不能作为 flex容器，因此，使用 justifyContent应该也是没有作用的。这个时候就只有用View包裹着了；注意text里面的字体大小；也会影响到

# **shadow和elevation**

- shadow（阴影）开头的样式现在可以在iOS上应用，但在安卓中是不生效的.
- 而Android上对应的属性是elevationelevation。  设置elevation属性就等价于使用原生的elevation API，因而也有同样的限制（比如最明显的就是需要Android 5.0以上版本）。此外还会影响到层叠视图在空间z轴上的顺序。 而且不设置backgroundColor阴影是不会生效的；

可以的话：推荐一些阴影插件 使用：[UI展示类（一）](UI展示类（一）.md "UI展示类（一）")

```javascript 
ios: {
  shadowColor: '#000',
  shadowRadius: 5,
  shadowOpacity: 0.1,
  shadowOffset: { height: 0, width: 0 },
},
android: {
  elevation: 5,
},
```

## Valuse 取值&#x20;

### Color 颜色&#x20;

React Native 支持了 CSS 中大部分的颜色类型：&#x20;

- \#f00 (#rgb)
- \#f00c (#rgba)：CSS 中无对应的值
- \#ff0000 (#rrggbb)
- \#ff0000cc (#rrggbbaa)：CSS 中无对应的值
- rgb(255, 0, 0)
- rgba(255, 0, 0, 0.9)
- hsl(360, 100%, 100%)
- hsla(360, 100%, 100%, 0.9)
- transparent
- 0xff00ff00 (0xrrggbbaa)：CSS 中无对应的值
- Color Name：支持了 [基本颜色关键字](http://css.doyoe.com/appendix/color-keywords.htm#basic "基本颜色关键字") 和 [拓展颜色关键字](http://css.doyoe.com/appendix/color-keywords.htm#extended "拓展颜色关键字")，但不支持 [28个系统颜色](http://css.doyoe.com/appendix/color-keywords.htm#system "28个系统颜色")；

## Units 单位&#x20;

### Pt 点&#x20;

在 React-Native 中，并不支持百分比单位，目前只支持一种单位，即 pt 绝对长度单位，同时，你在定义时不需要加单位，例如：&#x20;

```typescript 
<View style={{width: 100, height: 50}}></View> 

var styles = StyleSheet.create({     
  box: {         
    width: 100,         
    height: 50     
  } 
}); 
```


## PixelRatio 像素密度&#x20;

在 React-Native 中，访问设备像素密度的方法由 PixelRatio 类提供。&#x20;

我们的应用通常都会运行在不同的设备上，并且这些设备的像素密度很有可能各不相同。这会造成一个现象就是：&#x20;

- 定义了元素的边框为 1像素，而实际上在不同像素密度的设备上结果不一样，比如：iPhone6 显示为 2像素，iPhone6 Plus 显示为 3像素；
- 对于一个图片来讲，因为设备的像素密度不同，它也需要对应不同尺寸的规则，以防止图片过小变得模糊；

### 根据像素密度指定边框厚度&#x20;

出于对产品体验的一致性，我们会要求不论是在哪种设备上，其边框厚度都应该是相同的。一个取得物理上的相同边框厚度的好方法就是用逻辑尺寸除以像素密度比：&#x20;

var styles = StyleSheet.create({     box: {         borderWidth: 1 / PixelRatio.get(),         borderStyle: solid     } });&#x20;

上述代码将保证你的应用在所有的设备上（像素密度），都获得 1像素 的边框厚度。PixelRatio 通过 get() 方法来返回设备的像素密度。&#x20;
