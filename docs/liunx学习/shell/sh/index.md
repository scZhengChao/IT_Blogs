# **`set -e`**

**`set -e`****（或****`set -o errexit`）****让脚本在遇到任何错误（命令返回非零退出状态）时立即退出**，而不是继续执行后续命令。

**为什么需要**\*\*`set -e`？\*\*​

默认情况下，Shell 脚本即使某条命令失败（返回非零退出码），也会继续执行后续命令。这可能导致：

- **隐藏错误**：脚本可能在不该继续的情况下继续运行，导致更严重的问题。
- **难以调试**：错误可能被后续命令掩盖，难以定位问题根源。

`set -e`的作用就是 **让脚本在出错时立即停止**，避免“带病运行”。
