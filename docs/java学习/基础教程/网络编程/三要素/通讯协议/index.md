协议：计算机网络中，**连接和通信的规则被称为网络通信协议**

UDP协议

用户数据报协议(User Datagram Protocol)

- UDP是**面向无连接**通信协议。
  &#x20;      **速度快**，有大小限制**一次最多发送64K**，**数据不安全，易丢失数据**。

1. 面向无链接
2. 速度快
3. 最多64k
4. 数据不安全；容易丢失

tcp

**传输控制协议 (Transmission Control Protocol)**
TCP协议**是面向连接的**通信协议。
&#x20;      **速度慢，没有大小限制，数据安全。**

1. 面向有链接
2. 速度慢
3. 大小无限制
4. 数据相对安全
