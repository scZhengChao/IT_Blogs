# Math

- 不能被继承 final 关键字修饰类
- 不能创建对象 private 关键字修饰构造方法
- 对外提供静态方法

```java 
int a = 10;
        int b= 20;
        int m = Math.max(a,b);
        int n = Math.min(a,b);
        double p = Math.pow(a,2);
        double m6 = Math.random();
        long d2 = Math.round(4.6);
        System.out.println(p);
```
