# 在Mybatis中使用的占位符： &#x20;

\#{key} : 在映射文件中做为sql的占位符参数使用 &#x20;

\${key} : 在核心配置文件中获取外部配置文件中的数据; &#x20;

&#x20;        在映射文件中做为sql的占位符参数使用（注意细节：需要使用@Param("参数")声明参数名） &#x20;

&#x20;

# #{key}和\${key}的区别：&#x20;

\#{}：底层是使用`PreparedStatement`对象，\*\*对sql进行预编译，使用占位符。  好处：防止SQL注入  \*\*

\${}：底层是使用`Statement`对象，**对SQL进行拼接。  会有SQL注入风险**
