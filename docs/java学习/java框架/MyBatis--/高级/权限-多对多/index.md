# 权限-多对多

程序中的权限管理： &#x20;

1. 权限 //生活中：职责 &#x20;
2. 用户 //生活中：职员 (职员就职于一个职位) &#x20;
3. 角色 //生活中：职位（职位具备多个职责） &#x20;

权限管理基础表： 权限表、用户表、角色表 &#x20;

问题1： 一个用户可以有多个角色吗？     可以 &#x20;

问题3： 一个角色可以被多个用户使用吗？  可以 &#x20;

问题4： 一个角色可以有多个权限吗？     可以 &#x20;

问题5： 一个权限可以被多个角色使用吗？  可以 &#x20;

权限管理需要的表：\*\* 用户表 <=用户角色表=> 角色表 <=角色权限表=> 权限表  \*\*

在开发领域就有了一种技术名词： 权限5张表
