# 增删改查

```javascript 
// 添加
list.add(2,10); // 向2的位置上添加元素值；如果原来2的位置上已经有值了；会自动向后移动

// 修改
list.set(2,100);

// 删除
list.remove(2);

// 获取
list.get(2);


```
