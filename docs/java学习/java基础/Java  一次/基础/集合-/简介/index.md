# 有什么好处

1. **长度大小可变**
2. 可以**存储多种类型**
3. 底层使用了数据结构；效率高

# 特点

1. 不能存储**基本类型数据**（会**自动装箱**）
2. 分为两大类；`map`。和 `collection` （都是**接口**）都在utils包下面
   1. `collection` 分为`List` 和 `Set`
