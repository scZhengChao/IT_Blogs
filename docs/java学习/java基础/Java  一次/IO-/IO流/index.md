# 解决了什么问题；

- 通过变量,数组,或者集合存储数据,都是不能永久化存储 , 因为数据都是存储在内存中；只要代码运行结束，所有数据都会丢失。
- **把程序中存储在内存中的数据；写入到文件中；**
- **把磁盘文件中存储的数据；提取到内存中**

# IO流

其中：

- I  表示`intput`  ，是数据从硬盘进内存的过程，称之为读数据。
- O 表示`output` ，是数据从内存到硬盘的过程。称之为写数据。

在数据传输的过程中，是谁在读？是谁在写？这个参照物是谁？

IO的数据传输，可以看做是一种数据的流动，按照流动的方向，以**内存为参照物**，进行读写操作。

简单来说：**内存在读，内存在写。**

### 区别

- 字节流；**万能流；所有类型文件；**
- 字符流；**纯文本文件**（记事本能打开并且能看的懂大的）
