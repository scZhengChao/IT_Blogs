# 特点

可以把对象以\*\*字节的形式写到本地文件，直接打开文件，是读不懂的，需要再次用对象操作流读到内存中。  \*\*

- ## `ObjectInputSteam`

- ## `ObjectOutputStream`
  ```java 
  Object writeObject() 
  ```

- 对象操作流分为两类：对象操作**输入流和对象操作输出流**
- 对象操作输出流（对象**序列化**流）：就是**将对象写到本地文件中，或者在网络中传输对象**
