# 流的三类方法

- 获取Stream流
  创建一条流水线，并把数据放到流水线上准备进行操作
- 中间方法
  流水线上的操作。
  一次操作完毕之后，还可以继续进行其他操作。
- 终结方法
  一个Stream流只能有一个终结方法
  是流水线上的最后一个操作
