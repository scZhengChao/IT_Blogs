# 解析注解的技巧

- 注解在哪个成分上，我们就**先拿哪个成分对象**。
- &#x20;比如注解作用成员方法，则要获得该成员方法对应的Method对象，再来拿上面的注解
- &#x20;比如注解作用在类上，则要该类的Class对象，再来拿上面的注解
- &#x20;比如注解作用在成员变量上，则要获得该成员变量对应的Field对象，再来拿上面的注解
