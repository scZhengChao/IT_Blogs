# &#x20;获取和设置线程名称

在java 程序中运行的下场都有自己的名字。

![](image_yNVGDyRfps.png)

- 获取线程的名字

```java 
String getName​()：返回此线程的名称



```


- Thread类中设置线程的名字

```java 
void setName​(String name)：将此线程的名称 更改为等于参数 name
 通过构造方法也可以设置线程名称
```


获得当前线程的对象

```java 
public static Thread currentThread() ：返回对当前正在执行的线程对象的引用
```


线程休眠

```java 

public      void sleep(long time)：让线程休眠指定的时间， 单位为毫秒。 

public void join​() : 具备阻塞作用 , 等待这个线程死亡,才会执行其他线程 ; ( 挂起其他线程；仅当前线程运行 )
```


# 案例

```java title="thread"
package com.thread;

public class MyTask2 implements Runnable{
    @Override
    public void run() {
        try {
            // 等待当前线程执行完；才会执行其他线程
            Thread.currentThread().join();
        } catch (InterruptedException e) {
            throw new RuntimeException(e);
        }
        for (int i = 0; i < 100; i++) {
            Thread currentThread = Thread.currentThread();
            String name = currentThread.getName();
            System.out.println(name +" " + i );
        }
    }
}

```


```java title="main"
package com.thread;

public class Test2 {
    public static void main(String[] args) {

        new Thread(new MyTask2(),"zc").start();


        try {
            // 让当前线程休息5s(main线程)
            Thread.sleep(5000);
        } catch (InterruptedException e) {
            throw new RuntimeException(e);
        }

        for (int i = 0; i < 1000; i++) {
            System.out.println("main线程和 子线程 交替执行");
        }
    }
}

```
