# 解释

将类的**某些信息隐藏在类内部，不允许外部程序直接访问**

- **通过该类提供的方法**来实现对隐藏信息的操作和访问
- 隐藏对象的信息
- **留出访问的接口**

# 特点：

1、只能通过\*\*规定的方法访问数据
\*\*2、**隐藏类的实例细节，方便修改和实现**

我们只需知道如何使用，并不需要深究它的内部实现构造。
