在 Java 中，当存在继承关系的两个类进行实例化时，**静态代码块、构造代码块和无参构造方法**的执行顺序遵循严格的规则

### **执行顺序总结**

1. **父类静态代码块**（只在类首次加载时执行一次）
2. **子类静态代码块**（只在类首次加载时执行一次）
3. **父类构造代码块**（每次实例化时执行）
4. **父类无参构造方法**（每次实例化时执行）
5. **子类构造代码块**（每次实例化时执行）
6. **子类无参构造方法**（每次实例化时执行）

### **代码示例**

```java 
class Parent {
    static {
        System.out.println("父类静态代码块");
    }

    {
        System.out.println("父类构造代码块");
    }

    public Parent() {
        System.out.println("父类无参构造方法");
    }
}

class Child extends Parent {
    static {
        System.out.println("子类静态代码块");
    }

    {
        System.out.println("子类构造代码块");
    }

    public Child() {
        System.out.println("子类无参构造方法");
    }
}

public class Test {
    public static void main(String[] args) {
        new Child(); // 实例化子类
    }
}
```


#### **输出结果**

```java 
父类静态代码块
子类静态代码块
父类构造代码块
父类无参构造方法
子类构造代码块
子类无参构造方法
```


### **关键规则解析**

1. **静态代码块（****`static{}`****）**
   - 在类**首次加载**时执行（仅一次）。
   - 父类优先于子类执行。
2. **构造代码块（****`{}`****）**
   - 在**每次创建对象**时执行，且在构造方法之前执行。
   - 父类的构造代码块优先于子类执行。
3. **构造方法**
   - 默认会**隐式调用父类无参构造方法**（如果父类没有无参构造方法，需显式调用`super(...)`）。
   - 子类的构造方法最后执行。

### **内存与执行流程**

1. **类加载阶段**（JVM 方法区）
   - 加载父类 → 执行父类静态代码块
   - 加载子类 → 执行子类静态代码块
2. **对象实例化阶段**（堆内存）
   - 分配父类成员空间 → 执行父类构造代码块 → 父类构造方法
   - 分配子类成员空间 → 执行子类构造代码块 → 子类构造方法

***

### **特殊情况**

- **如果父类没有无参构造方法，** 子类必须显式调用`super(参数)`，否则编译报错。
- **静态代码块仅执行一次**，即使创建多个对象也不会重复执行。
