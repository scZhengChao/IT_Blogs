# 特点

- 接口不能实例化
- 没有构造方法；只能通过子类对象实现创造
- 可以多实现
- 实现了就**必须实现所有方法；否则就是抽象类；**
- 方法可以不写abstract；**默认都是abstract和 public**；属性默认都是；public static final
- 1.8 新增；default 和 static ；引用调用；
