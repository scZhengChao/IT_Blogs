# 为什么接口允许多继承

**接口只是定义了功能；没有实现；**

# 相同

- 接口和抽象类 都不能实例化
- 接口和抽象类，都具有抽象方法
- 接口和抽象类，都是做为父类型使用；

# 不同

- 抽象类除了抽象方法以外；还有成员变量、构造方法、非抽象方法
- 接口；除了抽象方法 以外；只有常量； （ : 默认方法和静态方法）（jdk9:私有方法）&#x20;

**类是用于描述事物；有属性有行为**

**接口只有行为；**
