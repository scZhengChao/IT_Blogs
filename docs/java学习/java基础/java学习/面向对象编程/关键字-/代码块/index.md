# 代码块

> **直接在类里出现**时；可以有多个；
> **构造代码块****优先于构造方法执行；
> 静态代码块****优先于构造代码块执行；****同类代码块谁在前面谁先执行；**可以用类名访问 **；也可以用对象访问；推荐默认类用**

**静态代码块无论实例化多少次；都只执行一次；构造代码块是实例化多少次就执行多少次**
