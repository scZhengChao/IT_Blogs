# 泛型编写

## 目录

- [解决什么问题](#解决什么问题)
- [使用](#使用)

编写泛型类比普通类要复杂。通常来说，**泛型类一般用在集合类中**，例如`ArrayList<T>`，**我们很少需要编写泛型类。**

如果我们确实需要编写一个泛型类，那么，应该如何编写它？

# 解决什么问题

- 在创建集合对象时；明确了所存储的数据类型
- 默认时object；不指定会需要强制转换；
- 在编译时对代码类型作判断；精简代码；避免错误；
- 在**编译时运行；运行时无用；**

# 使用

- 先明确时接口还是类
- 类中：成员变量不知道类型的时候
- 接口：成员方法中不知道返回类型的时候

```java 
public class  A<T>{} 
public interface B<E>{}

public <T> T C(T params){}
```
