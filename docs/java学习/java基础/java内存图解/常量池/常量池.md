## 一、Java常量池概述

Java常量池是JVM中一块特殊的内存区域，主要用于**存储编译期生成的各种字面量和符号引用**。常量池是Java实现高效内存管理的重要机制之一。

### 1. 常量池的类型

Java中有两种主要的常量池：

- **Class文件常量池**：存在于.class文件中
- **运行时常量池**：JVM运行时方法区的一部分

### 2. 常量池存储的内容

- 字面量：**文本字符串、final常量值等**
- 类和接口的全限定名
- 字段的名称和描述符
- 方法的名称和描述符

## 二、享元模式(Flyweight Pattern)原理

享元模式是一种结构型设计模式，主要用于减少**创建对象的数量**，以减少内存占用和提高性能。

### 享元模式的核心思想：

1. **共享细粒度对象**：将对象**中不变的内部状态(intrinsic)和可变的外部状态(extrinsic)分离**
2. **缓存和复用**：通过工厂方**法缓存和复用已创建的对象**

## 三、Java常量池中的享元模式实现

Java利用享元模式优化了字符串和基本类型包装类的内存使用。

### 1. 字符串常量池(String Pool)

```java 
String s1 = "hello";  // 从常量池获取
String s2 = "hello";  // 复用常量池中的"hello"
String s3 = new String("hello"); // 新建对象

System.out.println(s1 == s2); // true，同一对象
System.out.println(s1 == s3); // false，不同对象
```


**实现机制**：

- 使用StringTable(哈希表)存储字符串常量
- 调用intern()方法可以手动将字符串放入常量池

### 2. 基本类型包装类的缓存

```java 
Integer i1 = 127;  // 使用缓存
Integer i2 = 127;  // 复用缓存
Integer i3 = 128;  // 新建对象
Integer i4 = 128;  // 新建对象

System.out.println(i1 == i2); // true
System.out.println(i3 == i4); // false
```


**缓存范围**：

- Byte, Short, Integer, Long: -128\~127
- Character: 0\~127
- Boolean: true/false

## 四、享元模式在常量池中的优势

1. **内存节省**：相同值的对象只存储一份
2. **性能提升**：减少对象创建和垃圾回收开销
3. **快速比较**：可以直接用==比较(限于缓存范围内的对象)

## 五、实际应用注意事项

1. **字符串拼接**：

```java 
String a = "hello";
String b = "world";
String c = a + b;  // 编译期无法确定，不会放入常量池
```


1. **手动入池**

```java 
String s = new String("hello").intern(); // 强制放入常量池
```


1. **包装类比较**：

```java 
Integer x = 1000;
Integer y = 1000;
System.out.println(x == y); // false，超出缓存范围
System.out.println(x.equals(y)); // true，应使用equals比较
```


Java常量池通过**享元模式实现了高效的内存管理**，这是Java性能优化的重要设计之一。理解这一机制有助于编写更高效的Java代码。

- 包装类对象的**初始值**都是`null`
- java中除了`float`和`double`的其他基本数据类型，都有常量池；
  - 整数类型：\[-127,+127]值存在常量池； &#x20;
  - 字符类型；【0，127】对应的字符存在常量池； abc-efg
  - 布尔类型；true。false 存在常量池；&#x20;
