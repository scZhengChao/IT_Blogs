# 关键内存参数配置

| 参数                       | 说明      | 示例                            |
| ------------------------ | ------- | ----------------------------- |
| \`-Xms\`                 | 初始堆大小   | \`-Xms256m\`                  |
| \`-Xmx\`                 | 最大堆大小   | \`-Xmx1024m\`                 |
| \`-Xmn\`                 | 新生代大小   | \`-Xmn512m\`                  |
| \`-XX:MetaspaceSize\`    | 元空间初始大小 | \`-XX:MetaspaceSize=128m\`    |
| \`-XX:MaxMetaspaceSize\` | 元空间最大大小 | \`-XX:MaxMetaspaceSize=256m\` |
| \`-Xss\`                 | 线程栈大小   | \`-Xss1m\`                    |
