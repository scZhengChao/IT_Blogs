# 三层业务架构

## 目录

- [web层  （表现层）](#web层--表现层)
- [service层（业务层）](#service层业务层)
- [持久层（dao层）数据层](#持久层dao层数据层)

* 负责将数据到**保存到数据库的那一层代码**
* JavaEE三层架构 **：表现层、业务层、持久层**

# web层  （表现层）

- 只做参数接受和响应；不做复杂逻辑处理

# service层（业务层）

- 处理复杂的逻辑；返回数据

# 持久层（dao层）数据层

DAO即Data Access Object的缩写

通常是\*\*Web层调用业务层，\*\***业务层调用数据访问层**。**业务层负责处理各种业务逻辑，而数据访问层只负责对数据进行增删改查。**
