在 DBeaver 中，从 SQL 转储文件（如`.sql`文件）导入数据库，可以通过以下步骤完成。以下是详细的操作方法：

***

### **1. 准备工作**

- 确保你有一个 SQL 转储文件（如`dump.sql`）。
- 确保已经连接到目标数据库（MySQL、PostgreSQL、SQL Server 等）。

***

### **2. 使用 DBeaver 的 SQL 脚本执行功能**

#### **(1) 打开 SQL 编辑器**

1. 在 DBeaver 中，右键点击目标数据库或表。
2. 选择 **SQL 编辑器 > 新建 SQL 编辑器**。

#### **(2) 导入 SQL 文件**

1. 在 SQL 编辑器中，点击菜单栏的 **文件 > 打开文件**。
2. 选择你的 SQL 转储文件（如`dump.sql`），文件内容会加载到编辑器中。

#### **(3) 执行 SQL 脚本**

1. 点击工具栏的 **执行 SQL 脚本** 按钮（或按`Ctrl + Enter`）。
2. DBeaver 会逐行执行 SQL 文件中的语句，并将数据导入数据库。

- 如果你想一次性执行整个 SQL 脚本，可以点击 SQL 编辑器工具栏中的 “执行脚本” 按钮（带有多个绿色三角形的图标），或者使用快捷键`Ctrl + Shift + Enter`（Windows/Linux）或`Command + Shift + Enter`（Mac）。

***

### **3. 使用 DBeaver 的命令行工具**

如果 SQL 文件较大，可以使用 DBeaver 集成的命令行工具直接导入。

#### **(1) 打开命令行工具**

1. 在 DBeaver 中，右键点击目标数据库。
2. 选择 **工具 > 打开命令行工具**。

#### **(2) 导入 SQL 文件**

在命令行工具中，运行以下命令：

- **MySQL**：

```sql 
mysql -u <用户名> -p<密码> <数据库名> < dump.sql
```


- ​**SQL Server**：

```sql 
sqlcmd -S <服务器名> -U <用户名> -P <密码> -d <数据库名> -i dump.sql
```


### **4. 使用数据库自带的命令行工具**

如果 DBeaver 的命令行工具无法满足需求，可以直接使用数据库自带的命令行工具导入 SQL 文件。

#### **(1) MySQL**

```sql 
mysql -u <用户名> -p<密码> <数据库名> < dump.sql
```


#### **(2) SQL Server**

```sql 
sqlcmd -S <服务器名> -U <用户名> -P <密码> -d <数据库名> -i dump.sql
```


### **5. 注意事项**

- **文件编码**：确保 SQL 文件的编码与数据库的编码一致（通常为 UTF-8）。
- **文件大小**：如果 SQL 文件较大，建议使用命令行工具导入，避免 DBeaver 内存不足。
- **权限问题**：确保数据库用户有足够的权限执行 SQL 文件中的操作。

***

### **总结**

| **方法**​         | **适用场景**​ | **操作步骤**​             |
| --------------- | --------- | --------------------- |
| DBeaver SQL 编辑器 | 小型 SQL 文件 | 打开 SQL 文件，执行脚本        |
| DBeaver 命令行工具   | 中型 SQL 文件 | 使用 DBeaver 集成的命令行工具导入 |
| 数据库自带命令行工具      | 大型 SQL 文件 | 直接使用数据库命令行工具导入        |
