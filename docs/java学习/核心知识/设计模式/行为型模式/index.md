# 行为型模式

行为型模式主要**涉及算法和对象间的职责分配。通过使用对象组合，行为型模式可以描述一组对象应该**如何协作来完成一个整体任务。

行为型模式有：

- 责任链
- 命令
- 解释器
- 迭代器
- 中介
- 备忘录
- 观察者
- 状态
- 策略
- 模板方法
- 访问者
