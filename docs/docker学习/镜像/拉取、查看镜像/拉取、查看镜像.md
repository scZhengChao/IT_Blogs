需求：从DockerHub中拉取一个nginx镜像并查看

1）首先去镜像仓库搜索nginx镜像，比如[**DockerHub**](https://hub.docker.com/ "DockerHub")**:**

![](image_t87GizFtXQ.png)

2）根据查看到的镜像名称，拉取自己需要的镜像，通过命令：docker pull nginx

![](image_X4XmvL9qdb.png)

3）通过命令：docker images 查看拉取到的镜像

![](image_ZvWkqEAcTE.png)

# 查看远程镜像信息

```markdown 
docker search mysql
docker search xxx：查询远程镜像仓库指定镜像名称列表（默认展示25条）。

docker search xxx --limit 5：查询远程镜像仓库指定镜像名称列表，展示指定条数（此处5条）。



```


# 查看远程官方镜像信息

```docker 
docker search --filter "is-official=true" node
```


# 进一步查看镜像具体信息

```bash 
docker inspect nginx

```


# 查看空间信息

```markdown 

docker system df：查看镜像、容器、数据卷所占的空间信息。

```
