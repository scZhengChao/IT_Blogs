# 推送、拉取镜像

推送镜像到私有镜像服务必须先tag(版本)，步骤如下：

① 重新tag本地镜像，**名称前缀为私有仓库的地址**：[192.168.200.128](http://tnm2.oa.com/host/home/192.168.200.128 "192.168.200.128"):5000/

```bash 
docker tag nginx:latest 192.168.200.128:5000/nginx:1.0

```


说明：

> 1.nginx:latest 表示原来的镜像名和版本
>
> [2.192.168.200](http://tnm2.oa.com/host/home/2.192.168.200 "2.192.168.200").128:5000 私有仓库的地址
>
> 3.nginx:1.0 ：新的镜像和版本

![](image_JkFztElnbP.png)

② 推送镜像

```docker 
docker push 192.168.200.128:5000/nginx:1.0

```


![](image_Kc7zr6IcO8.png)

![](image_p6QPBF3OH7.png)

③ 拉取镜像

【1】先删除之前的镜像

```docker 
docker rmi 192.168.200.128:5000/nginx:1.0 nginx:latest

```


【2】在拉取新的镜像

```docker 
docker pull 192.168.200.128:5000/nginx:1.0
```
