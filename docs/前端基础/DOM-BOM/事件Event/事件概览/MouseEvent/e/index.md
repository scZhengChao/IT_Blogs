# e

- `e.button` 标识用户按下或释放的是哪个鼠标按钮。这个属性在处理多按钮交互（如左键、右键、中键操作）时非常有用。

| 值     | 含义              | 对应鼠标按钮          |
| ----- | --------------- | --------------- |
| \`0\` | 主按钮（通常是左键）      | 左键（或单按钮设备的唯一按钮） |
| \`1\` | 辅助按钮（通常是中键）     | 中键（滚轮按钮）        |
| \`2\` | 次要按钮（通常是右键）     | 右键              |
| \`3\` | 第四个按钮（通常是浏览器后退） | 浏览器后退按钮         |
| \`4\` | 第五个按钮（通常是浏览器前进） | 浏览器前进按钮         |
