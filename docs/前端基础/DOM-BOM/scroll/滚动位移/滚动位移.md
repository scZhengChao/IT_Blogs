# scroll三兄弟

- scrollBy(x,y) 会使元素每隔一秒从当前的滚动条位置向下滚动10px，这是一个设置相对滚动条位置的方法。
- scrollTo(x,y) 和 scroll() 方法是一样的，都是将元素滚动到指定位置，它们都是设置绝对滚动条位置。
- box.scrollTo(0,200)  box为具有滚动条的父元素  

**以上都不会有动画效果**

# scrollIntoView

- element.scrollIntoView();  // 等同于element.scrollIntoView(true)
- element.scrollIntoView(alignToTop);  // Boolean型参数
- element.scrollIntoView(scrollIntoViewOptions);  // Object型参数

## boolean参数

alignToTop (Boolean型参数)

1.如果为true，元素的顶端将和其所在滚动区的可视区域的顶端对齐。

2.如果为false，元素的底端将和其所在滚动区的可视区域的底端对齐。

## object对象参数

scrollIntoViewOptions (Object型参数)

```javascript 
{
    behavior: "auto"  | "instant" | "smooth",
    block:    "start" | "end",
}
```


1.如果是一个boolean，true 相当于{block: "start"}，false 相当于{block: "end"}

2.behavior这个选项决定页面是如何滚动的，实测auto与instant都是瞬间跳到相应的位置，而smooth就是有动画的过程

横向滚动

```javascript 
scrollIntoView({
  behavior: 'smooth',
  block: 'nearest',
  inline: 'center'
});
```


## 例子：

```javascript 
var element = document.getElementById("box");
element.scrollIntoView();
element.scrollIntoView(false);
element.scrollIntoView({block: "end"});
element.scrollIntoView({block: "end", behavior: "smooth"});
```


取决于其它元素的布局情况，此元素可能不会完全滚动到顶端或底端。

# 滚动优化：

## scroll-behavior

滚动平滑：使用 scroll-behavior: smooth 让滚动丝滑&#x20;

使用 scroll-behavior: smooth，可以让滚动框实现平稳的滚动，而不是突兀的跳动。

```javascript 
    nav{
      display: flex;
      justify-content: center;
      align-items: center;
      height: 50px;
    }
    nav a {
      flex: 1;
      color: white;
      background: black;
      display: block;
      height: 50px;
      text-align: center;
      line-height: 50px;
    }
    .g-container{
      border: 2px solid black;
      box-shadow: 0 0 1 gray;
    }
    .scrolling-box{
      height: 400px;
      overflow: auto;
      scroll-behavior: smooth;
    }
    section {
      height: 400px;
      display: flex;
      justify-content: center;
      align-items: center;
    }

 <div class="g-container">
    <nav>
      <a href="#1">
        1
      </a>
      <a href="#2">
        2
      </a>
      <a href="#3">
        3
      </a>
    </nav>
    <div class="scrolling-box">
      <section id="1">
        First section
      </section>
      <section id="2">
        Second section
      </section>
      <section id="3">
        Third section
      </section>
    </div>
```
