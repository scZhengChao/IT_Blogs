##### 直接通过获取UrL，利用浏览器跳转页面进行下载（window\.open或者模拟点击a标签)

这种方法适用于**不需要认证**，给我们文件地址就可以直接让浏览器代理下载的情况。但正常项目中的文件，很多需要进行POST请求，接口认证后才能进行文件下载，通常需要在header中添加认证信息，这就无法使用window\.open的方式实现了，进而不得不采用流式获取的方式，在js中接收数据。
