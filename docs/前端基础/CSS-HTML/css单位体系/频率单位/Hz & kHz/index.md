# Hz & kHz

CSS中的频率单位有两个：赫兹（Hz）和千赫兹（kHz）。它们的换算关系如下：

```javascript 
1kHz = 1000Hz
```


通常情况下，**频率单位使用在听或说级联样式表**中。**频率可以被用来改变一个语音阅读文本的音调。低频率就是低音**，高**频率就是高音。**

```javascript 
.low { 
  pitch: 105Hz; 
} 
.squeal { 
  pitch: 135Hz; 
}

```


**需要注意，当数值为0时，单位对值没有影响，但是单位是不能省略的。也就是说0、0Hz、0kHz是不一样的。所以，在使用频率单位时，不要直接写0。另外，这两个单位是不区分大小写的。**
