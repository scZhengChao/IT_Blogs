# grid王者到来

首先我们看下grid的支持情况，从下面的图片可以看到，主流浏览器都是支持的，特别是在最新版的ie也采用和chrome一样的内核之后，可以说现在前端开发终于迎来了最幸福的时刻。

![  ](./image/85981af1a278bece252c0e2638a9128d_xZvpTRM5Vc.png "  ")

           这是一个非常棒的布局解决方案。自从网络诞生以来，我们就一直在努力设计我们的网站，强迫他们去适应和使用那些不适合他们的方式。

          不过网格布局的出现，直接从浏览器解决了我们布局的复杂性，我们不再需要复杂的css来生成网格布局，不需要使用`bootstrap`这样的网格框架来布局，我们可以使用简单的grid布局来完成。
