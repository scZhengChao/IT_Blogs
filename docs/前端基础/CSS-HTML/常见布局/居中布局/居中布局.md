### grid

在没有和flex grid之前，垂直居中一直不能很优雅的实现。而现在，可以结合我们`grid`和`place-items`优雅的实现同时**水平居中**和**垂直居中**。

```javascript 

<div class="parent blue" >
  <div class="box coral" contenteditable>
    :)
  </div>
.ex1 .parent {
  display: grid;
  place-items: center;
}

```

# position

**缺点：必须知道宽高；**

```sass (scss)  
.wraper {
    position: relative;
    .box {
        position: absolute;
        top: 50%;
        left: 50%;
        width: 100px;
        height: 100px;
        margin: -50px -50px;
    }
}
```


# position margin: auto

**这个也不需要知道宽高；**

```sass (scss)  
//margin:auto实现绝对定位元素的居中
.element {
    width: 600px; 
    height: 400px;
    position: absolute; left: 0; top: 0; right: 0; bottom: 0;
    margin: auto; /* 有了这个就自动居中了 */
}
```


# transform&#x20;

优点： **不需要知道宽高**

```sass (scss)  
.wraper {
    position: relative;
    .box {
        position: absolute;
        top: 50%;
        left: 50%;
        transform: translate(-50%, -50%);
    }
}
```


# flex

**最常用的布局**

```sass (scss)  
.wraper {
    .box {
        display: flex;
        justify-content:center;
        align-items: center;
        height: 100px;
    }
}
```


# table-cell

**为了使用vertical-align, 我们需要设置父元素display:table,**

```sass (scss)  
  // 子元素 display:table-cell;vertical-align:middle;
    .parent{
        width: 600px;
        height: 600px;
        border: 1px solid black;
        display:table-cell;
        vertical-align: middle;
    }
    .son{
        background: chartreuse;
        width: 100px;
        height: 100px；
       
    }
```


# calc

**calc：需要动态计算**

```sass (scss)  
//块级元素：calc()
.parent {
    width: 300px;
    height: 300px;
    border: 1px solid red;
    position: relative;
}
.child {
    width: 100px;
    height: 100px;
    background: blue;
    padding: -webkit-calc((100% - 100px) / 2);
    padding: -moz-calc((100% - 100px) / 2);
    padding: -ms-calc((100% - 100px) / 2);
    padding: calc((100% - 100px) / 2);
    background-clip: content-box;
}
```


# inline-block, vertical-align

需要利用到 **伪类元素**

```sass (scss)  
//垂直居中display: inline-block, 
//vertical-align: middle和一个伪元素
  .parent{
        width: 600px;
        height: 600px;
        border: 1px solid black;
        margin: 0 auto;
    }
    .parent::after{
        content: '';
        height: 100%;
        width: 0;
        display: inline-block;
        vertical-align: middle;
    }
    .son{
        background: chartreuse;
        width: 100px;
        height: 100px;
        display: inline-block;
        vertical-align: middle;
    }
```


# flex和margin：auto

```sass (scss)  
// flex和margin：auto 配合垂直水平居中
<div class="parent">
    <div class="child"></div>
</div>
.parent {
    width: 300px;
    height: 200px;
    background: #ccc;
    display: flex;
}
.child {
    width: 50px;
    height: 50px;
    background: #000;
    margin: auto;
}
```
