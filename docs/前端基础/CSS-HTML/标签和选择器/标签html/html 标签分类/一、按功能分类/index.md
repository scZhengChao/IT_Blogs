### 1. 文档结构标签

```html 
<!DOCTYPE html>  <!-- 文档类型声明 -->
<html>          <!-- 根元素 -->
<head>          <!-- 文档头部 -->
<body>          <!-- 文档主体 -->
```


### 2. 元信息标签

```html 
<meta>          <!-- 文档元数据 -->
<title>         <!-- 文档标题 -->
<link>          <!-- 外部资源链接 -->
<style>         <!-- 内联CSS -->
<script>        <!-- JavaScript代码 -->
<base>          <!-- 基准URL -->
```


### 3. 内容分区标签

```html 
<header>        <!-- 页眉 -->
<nav>           <!-- 导航栏 -->
<main>          <!-- 主内容 -->
<section>       <!-- 文档章节 -->
<article>       <!-- 独立内容 -->
<aside>         <!-- 侧边栏 -->
<footer>        <!-- 页脚 -->
```


### 4. 文本内容标签

```html 
<h1>-<h6>       <!-- 标题 -->
<p>             <!-- 段落 -->
<br>            <!-- 换行 -->
<hr>            <!-- 水平线 -->
<pre>           <!-- 预格式化文本 -->
<blockquote>    <!-- 长引用 -->
<q>             <!-- 短引用 -->
```


### 5. 内联文本语义

```html 
<a>             <!-- 超链接 -->
<strong>        <!-- 重要文本 -->
<em>            <!-- 强调文本 -->
<mark>          <!-- 标记文本 -->
<small>         <!-- 小号文本 -->
<del>           <!-- 删除文本 -->
<ins>           <!-- 插入文本 -->
<sub>           <!-- 下标 -->
<sup>           <!-- 上标 -->
```


### 6. 图片和多媒体

```html 
<img>           <!-- 图片 -->
<audio>         <!-- 音频 -->
<video>         <!-- 视频 -->
<source>        <!-- 多媒体资源 -->
<track>         <!-- 字幕 -->
<canvas>        <!-- 画布 -->
<svg>           <!-- SVG图形 -->
```


### 7. 表格标签

```html 
<table>         <!-- 表格 -->
<caption>       <!-- 表格标题 -->
<thead>         <!-- 表头 -->
<tbody>         <!-- 表体 -->
<tfoot>         <!-- 表尾 -->
<tr>            <!-- 表格行 -->
<th>            <!-- 表头单元格 -->
<td>            <!-- 表格数据单元格 -->
```


### 8. 表单标签

```html 
<form>          <!-- 表单 -->
<input>         <!-- 输入控件 -->
<textarea>      <!-- 多行文本输入 -->
<button>        <!-- 按钮 -->
<select>        <!-- 下拉列表 -->
<optgroup>      <!-- 选项分组 -->
<option>        <!-- 选项 -->
<label>         <!-- 标签 -->
<fieldset>      <!-- 表单分组 -->
<legend>        <!-- 分组标题 -->
<datalist>      <!-- 输入选项列表 -->
<output>        <!-- 计算结果 -->
```


### 9. 交互元素

```html 
<details>       <!-- 详情 -->
<summary>       <!-- 详情摘要 -->
<dialog>        <!-- 对话框 -->
<menu>          <!-- 菜单 -->
```
