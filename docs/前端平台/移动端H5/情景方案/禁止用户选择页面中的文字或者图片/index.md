# 禁止用户选择页面中的文字或者图片

## 目录

- [禁止保存或拷贝图像](#禁止保存或拷贝图像)

```css 
div {  
  -webkit-touch-callout: none;  
  -webkit-user-select: none;  
  -khtml-user-select: none;  
  -moz-user-select: none;  
  -ms-user-select: none;  
  user-select: none;  
}
```


### 禁止保存或拷贝图像

```css 
img {  
  -webkit-touch-callout: none;  
}
```
