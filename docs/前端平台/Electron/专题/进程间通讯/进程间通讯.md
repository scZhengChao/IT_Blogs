# 进程间通讯

进程间通信 (`IPC`) 是在 `Electron` 中构建功能丰富的桌面应用程序的关键部分之一。 由于主进程和渲染器进程在 `Electron` 的进程模型具有不同的职责，因此 `IPC` 是执行许多常见任务的唯一方法，例如从 `UI` 调用原生 `API` 或从原生菜单触发 `Web` 内容的更改。
