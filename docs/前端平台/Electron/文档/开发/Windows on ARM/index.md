# Windows on ARM

如果您的应用使用`Electron 6.0.8`及之后的版本，您现在可以在基于`ARM`的`Windows10`上构建它。 这大大提高了性能，但需要重新**编译应用中使用的任何原生模块。** 它还可能**需要对生成和打包脚本进行小的修改**。
