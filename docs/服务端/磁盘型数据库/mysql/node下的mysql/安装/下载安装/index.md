#### Mac安装Mysql(8.0)版本

1.首先[打开Mysql](https://so.csdn.net/so/search?q=打开Mysql\&spm=1001.2101.3001.7020 "打开Mysql")的官方网站 [点击跳转到官网](https://www.mysql.com/ "点击跳转到官网")
2.进入页面后点击DOWNLOADS

![](./image/image_3ZUMSjt77F.png)

3.进入Downloads页面后，下滑页面选择MySQL Community （[GPL](https://so.csdn.net/so/search?q=GPL\&spm=1001.2101.3001.7020 "GPL")） Downloads »

![](./image/image_R77G_oHI4q.png)

4.进入页面后，点击MySQL Community Server

![](./image/image_RnxR6UvRkm.png)

5.按照图片选择对应的版本(8.0)、系统(macOS)和处理器(ARM)

![](./image/image_NDgXhocSjX.png)

6.点击No thanks, just start my download.进行下载

![](./image/image_fWgtTuFpgj.png)

7.打开安装包，一直点击继续无脑安装，在Configuration安装页面中选择第一种设置密码方式，并点击Next

![](./image/image_0qW_59XKdT.png)

8.在进入下一个页面后，设置Mysql登录密码,之后点击Finnish完成安装

![](./image/image_2AaDQIorOr.png)

9.打开系统偏好设置，点击Mysql出现此画面则证明安装成功

![](./image/image_sgfVVFa4qM.png)
