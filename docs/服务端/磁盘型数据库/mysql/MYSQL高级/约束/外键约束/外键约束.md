# 概述

外键就是**从表中设定一个字段**，**用来保存主表中的主键值。**外键**约束了从表的外键值只能是主表的主键值。**

> **注意：现有外键字段；再有外键约束**
> 加约束只是为了限制乱写外键；（写了一个主表没有的主键）；只是限制数据合法

# 外键定义语法

### 方式1：创建表时创建外键（常用）

```sql 
CREATE TABLE 表名 (
    其他字段 
    外键字段名 int,
    CONSTRAINT 外键名 FOREIGN KEY (当前表外键字段名) REFERENCES 主表名 (主表主键)
);


```


> 外键名 ≠ 外键字段名； 外键名是自己取得

### 方式2：修改字段为外键

```sql 
ALTER TABLE 表名
    ADD CONSTRAINT 外键名 FOREIGN KEY (当前表外键字段名) REFERENCES 主表 (主表主键);


```


### 外键删除语法（了解，不常用）

```sql 
alter table 从表名 drop foreign key 外键名称;
```

# 作用

- **建立表与表之间的关系**
- **预约从表的外键和主表的主键保持一致；**

# 外键约束操作注意事项

### 添加数据时:

- 先添**加主表中的数据,再添加从表中的数据**

### 删除数据时:

- 先**删从表中的数据,再删主表中的数据**

### 修改数据时:

- 如果主表中的\*\*主键被从表引用了,不能修改此主键的值
  \*\*

扩展：外键的级联

**如果要实现主表数据删除，更新操作，对应从表数据也同时删除，更新操作该怎么办呢？**

级联操作可以完成以上需求，**级联操作就是在修改或者删除主键时可以同时对从表的外键进行修改删除;**

### 级联设置语法：

`on update cascade `
&#x9;**表示主表进行更新操作后,从表对应的数据也要进行更新操作;**`on delete cascade
`	**表示主表进行主键删除后,从表外键对应的数据也要删除;**

两个都要；俩个都写

\*\*
\*\*例如，将上一练习中的employee表外键设置为级联更新，级联删除：

```sql 
ALTER TABLE employee
    ADD CONSTRAINT fk_coder FOREIGN KEY (dep_id) REFERENCES department (id) ON UPDATE CASCADE ON DELETE CASCADE;


```
