### 1.主键概述

&#x20;
设定表中某一字段为主键，那么该字段所在列的数**据就能够唯一的标识表中的每一行数据（作用）**
设定为主键的字段一般和业务无关列有这些特点: **1. 唯一，2. 非空 ，3. 非业务相关。**

- 提高查询效率
- 和外键建立表关系

### 2.主键的定义及删除语法

&#x20;
2.1 在建表时进行指定&#x20;
主键是给数据库和程序使用的，不是给最终的客户使用的。所以主键字段与业务没有关系，只要不重复，非空就行。通常会单独给每张表设计一个id的字段，把id作为主键，如下：

```sql 
CREATE TABLE 表名 (
    id int PRIMARY KEY,
    其他字段,
    ...
);


```


&#x20;    &#x20;
2.2 在已有表中进行指定（原来表没有主键）

```sql 
ALTER TABLE 表名
    ADD PRIMARY KEY (字段);


```


> **主键必须唯一**:

2.3 删除主键语法

```sql 
ALTER TABLE 表名
    DROP PRIMARY KEY;


```


### 3.主键自增

主键如果让我们自己添加很有可能重复的主键而导致数据添加失败，我们通常希望在每次插入新记录时,数据库自动生成主键字段的值

主键添加语法：

```sql 
字段名 字段类型 primary key auto_increment;
```

### 4.DELETE和TRUNCATE删表对id的影响

1. delete删除表中的数据，**不重置auto\_increment的值**
2. truncate**摧毁表，重建表，auto\_increment重置为0**；下次从1开始&#x20;

### 5.设置主键从指定值自增

如果想自定义id的值,可以使用下面的sql进行设置,一般不做设置，设 如下：

```sql 
alter table 表名 auto_increment = 起始值;
```


> 注意：应该在具有**自增约束的情况下执行上述语句。**
