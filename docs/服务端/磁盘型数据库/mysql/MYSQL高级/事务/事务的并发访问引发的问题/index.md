2.不可重复读：

在一个事务**内多次读取表中的数据，多次读取的内容不同**，多发生在**其他事务update操作**时;

![](./assets/image/image_p3Bex_lEvg.png)

3.幻读（虚读）

一个事务内读取**到了别的事务插入或者删除的数据，导致前后读取记录行数不同,多发生在delete或insert时**；&#x20;
