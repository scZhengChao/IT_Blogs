# 概念

- 数据库的事务（Transaction）是一**种机制、一个操作序列，包含了一组数据库操作命令**
- 简单理解 : 如果一个包含多个步骤的业务操作 , 被事务管理 , 要么这些**操作同时操作成功 , 要么同时失败**
- 事务是**一个不可分割的工作逻辑单元**

\-- 开启事务`START TRANSACTION;`\-- 提交事务`COMMIT;`-- 回滚事务`ROLLBACK;`

> mysql默认：一行sql语句就是会自动提交
> 事务：**逻辑单元；** 可以在事务中书写多行sql语句；**这些sql语句会作为一个整体**；要么全部成功；要么全部失败；

# 操作

### MYSQL中两种事务的操作方式：

1. 手动提交事务 **：先开启，再提交；**
2. 自动提交事务(默认的)：在执行一条sql语句时自动开启及提交一次事务；

### 手动提交事务SQL语句&#xD;

- 开启事务： start transaction;
- 提交事务： commit;
- 回滚事务： rollback;

修改事务的默认提交方式：

- 事务提交的两种方式：
  &#x9;第一 : 自动提交：
  &#x9;	mysql就是自动提交的
  &#x9; 	一条DML(增删改)语句会自动提交一次事务。
  &#x9;第二 : 手动提交：
  &#x9;	Oracle默认就是手动提交事务
  &#x9;	需要先开启事务，再提交
- 修改事务的默认提交方式：
  &#x9;查看事务的默认提交方式：`SELECT @@autocommit`;&#x20;
  &#x9;\*\*1 代表自动提交 &#x20;
  &#x9;0 代表手动提交
  \*\*&#x9;
- 修改默认提交方式： **set @@autocommit = 0;** &#x20;

> **注意 : 如果修改了手动提交任务,增删改之后需要执行commit**
> @@: 全局变量；或者全局参数
