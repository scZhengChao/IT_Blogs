# 概念

子查询就是将**一个查询的结果做为另一个查询的条件**，形成查询语句的嵌套，嵌套的SQL查询就是子查询，子查询语句需要使用括号括起来。

# 分类

根据子句查询的结果，我们可以将子查询**进行分成三类**，结果为**单行单列，结果为多行单列，结果为多行多列。**

# 单行单列

如果子查询是**单行单列**，父查询使用比较运算符：`> < =` &#x20;

#### 练习

查询最高工资的员工信息

```sql 
select * from emp where salary = (select max(salary) from emp);
```


查询工资大于"蜘蛛精"的员工

```sql 
select * from emp where salary > (select salary from emp where name='蜘蛛精');

```


# 多行单列

如果子查询是**多行单列，可以认为是一个数组**，父查询使用`in`、`any` 、`all`关键字

![](image_cvIBft42zK.png)

### 练习

![](image_x_zVRsMgXa.png)

例如，还是以之前的部门，员工表为例：
查询所有 员工其部门信息

```sql 
select * from dept where id in ( select dept_id from emp where salary > 5000 );   
```


查询工资**高于1号部门所有员工**工资的员工信息（改成max 就变成了单列）

```sql 
select * from emp where salary > all (select salary from emp where dept_id=1);
```


查询工资**高于1号部门任意一位员**工工资的员工信息（改成min就变成了单列）

```sql 
select * from emp where salary > any (select salary from emp where dept_id=1);
```


# 多行多列

如果子查询是多行多列，子查询可以认为它是**一张虚拟表，可以**使用表连接再次进行多表查询

> **注意：如果**要访问子查询表的字段，&#x20;

![](image_TpwCRIM5_x.png)

### 练习

例如，还是以之前的部门，员工表为例，查询出2011年以后入职的员工信息，
包括部门名称
实现步骤：
在员工表中查询2011-1-1以后入职的员工

```sql 
select * from emp where join_date > '2011-1-1';
```


查询所有的部门信息，与上面的虚拟表中的信息组合，找出所有部门id等于的dept\_id

```sql title=" "
select * from dept  d  inner join (select * from emp where join_date > '2011-1-1') e on d.id = e.dept_id;

```


使用右连接，否则没有部门的员工信息查询不到

```sql 
select * from  dept d right join (select * from emp where join_date > '2011-1-1') e on d.id = e.dept_id;  
```
