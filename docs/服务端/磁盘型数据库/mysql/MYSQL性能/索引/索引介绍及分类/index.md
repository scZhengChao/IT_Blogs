## 分类

- 主键（约束）索引  &#x20;

&#x20;主键约束(唯一+非空) + 提高查询效率

- 唯一（约束）索引   &#x20;

唯一约束 + 提高查询效率

- 普通索引   &#x20;

仅提高查询效率

- 组合（联合）索引   &#x20;

多个字段组成索引   &#x20;

\[联合主键索引、联合唯一索引、联合普通索引]

- 全文索引 TEXT BIGTEXY   &#x20;

Mysql全文索引使用较少，基本针对文档类数据会选择solr、es等文档搜索类数据库；

- hash索引   &#x20;

根据key-value等值查询效率非常高，但是不适合范围查询&#x20;
