#### 常用命令

| 命令                | 功能                    |
| ----------------- | --------------------- |
| hset 键 字段 值       | 添加键，字段，值              |
| hget 键 字段         | 通过键，字段得到值             |
| hmset 键 字段 值 字段 值 | multiply多个，一次添加多个字段和值 |
| hmget 键 字段 字段     | 通过键，获取多个字段和值          |
| hdel 键 字段 字段      | 删除一个或多个字段的值           |
| hgetall 键         | 得到这个键下所有的字段和值         |
| HKEYS 键           | 获取哈希表中所有字段            |
| HVALS 键           | 获取哈希表中所有值             |

#### 小结

| 功能       | hash类型的操作命令 |
| -------- | ----------- |
| 添加值      | hset        |
| 得到值      | hget        |
| 删除值      | hdel        |
| 添加多个字段   | hmset       |
| 得到多个字段值  | hmget       |
| 得到所有字段的值 | hgetall     |
